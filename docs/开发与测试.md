# 开发与测试

游戏入口和运行文件的 SHA-256 记录在 [源码清单](game-sources.json)。每个清单条目的文件路径相对于该游戏的目录。游戏以原始代码发布，图片为该游戏画面的截图。

各项目文档保留原开发阶段的测试结论。文档中提及的本地备份、部分浏览器取证脚本、历史日志和完整截图集属于原交付环境。仓库中的测试覆盖可在下列命令中重跑。

## 核心测试

在仓库根目录使用 Node.js 20 或更新版本。下列命令使用 Node.js 自带模块，分别测试游戏逻辑、关卡或规则回归。

| 游戏 | 命令 |
| --- | --- |
| 长夜点灯 | `node --test games/deepseek/tests/core.test.js` |
| 星港守夜人 | `node --test games/kimi/tests/mechanics.test.cjs games/kimi/tests/state-flow.test.cjs games/kimi/tests/hp-matrix.test.cjs` |
| 墨影·守夜人 | `node games/mimo/game/tests/run-tests.js` |
| 星尘幸存者 | `node games/doubao/tests/run-tests.cjs` |
| 回响 ECHO | `node games/hunyuan/tools/verify.js` 和 `node games/hunyuan/tools/regress.js` |
| 霓虹防线 | `node games/step/tools/simulate.js` |
| 御剑·破晓 | `node games/zhipu/tests/make-dev.js`，然后 `node games/zhipu/tests/run-tests.js` |
| 问道2048·修仙录 | `node games/qwen/tests/harness.mjs` |

御剑·破晓的自动测试需要生成开发版页面，正常游戏入口仍为该目录的 `index.html`。问道2048的测试会生成参考解文件。两个产物都列在 Git 忽略清单中。

长夜点灯的浏览器测试另需 `playwright-core` 和本机 Chrome，安装与启动方法见[游戏说明](../games/deepseek/README.md)。
