# 《墨影·守夜人》开发文档

- 版本：v2.0（第二轮）
- 日期：2026-11-02
- 对应设计文档：《游戏设计文档.md》v2.0
- 技术目标：零依赖、双击即玩、稳定 60fps、代码模块清晰可维护

---

## 1. 技术选型

| 项 | 选择 | 理由 |
|---|---|---|
| 渲染 | HTML5 Canvas 2D | 大量同屏实体，Canvas 批量绘制性能稳定 |
| 语言 | 原生 JavaScript（ES2017，经典 script 标签） | 无构建步骤；file:// 直开不受 ES Module CORS 限制 |
| 样式 | 原生 CSS | 仅覆盖 UI 层（HUD/卡片/菜单） |
| 音频 | WebAudio 振荡器合成 | 无外部音频资源，体积为零 |
| 存档 | localStorage | 满足最高纪录需求 |
| 依赖/构建 | 无 | 保证"双击即玩" |

**运行方式**：浏览器直接打开 `game/index.html`。目标浏览器：Chrome / Edge（Firefox、Safari 兼容）。

## 3. 架构设计

### 3.1 游戏状态机

```
        点击开始/Enter
 TITLE ───────────────► PLAYING ◄──────► PAUSED (Esc)
   ▲                      │  ▲                │
   │           经验满      │  │ 选完卡片        │
   │                      ▼  │               ▼
   │                   LEVELUP ───────────────┘(Esc 视为暂停)
   │                      │
   │            300 秒达成 │
   │                      ▼
   │              VICTORY ──Enter──► PLAYING(无尽，不再结算)
   │                │ E
   │                ▼
   └──── 再来一局 ── GAMEOVER ◄── 生命归零 ── PLAYING
```

- 状态常量：`'title' | 'playing' | 'levelup' | 'paused' | 'victory' | 'gameover'`
- `levelup` / `paused` / `victory` 时主循环继续渲染但**冻结逻辑更新**（dt 不推进世界）。

### 3.2 主循环

```js
function frame(now) {
    const dt = Math.min((now - last) / 1000, 0.05); // 钳制防跳帧穿模
    if (state === 'playing') world.update(dt);
    world.render();
    requestAnimationFrame(frame);
}
```

- 采用 **rAF + 变步长**（dt 钳制 50ms）。本游戏无不动物理，变步长足够稳定。
- 相机固定（战场 = 整个 Canvas），无滚动卷轴，规避坐标系统复杂度。

### 3.3 实体模型

统一采用**平坦数组 + 每帧过滤**管理（对象死亡置 `dead=true`，帧末 `filter`）：

| 集合 | 元素 | 峰值预算 |
|---|---|---|
| enemies | Enemy | 260（硬上限，超出停止刷怪） |
| bullets | Bullet（玩家弹 + 敌方弹，`friendly` 标志区分） | 200 |
| gems | Gem | 400（超出时合并经验到最近宝石） |
| particles | Particle | 500（超预算跳过新增） |
| floaters | Floater（飘字：伤害/拾取） | 120 |

实体基类字段：`x, y, r, dead`；圆形碰撞：`dist² < (r1+r2)²`（不开方）。

### 3.4 玩家（Player）

```js
{
  x, y, r: 15,
  hp, maxHp, speed, pickupRadius,
  level, xp, xpNext,
  invulnTimer, dashTimer, dashCdTimer,
  stats: { dmgMult, cdMult, xpMult, regen, speedMult },   // 强化叠层结果
  weapons: { orbit: Lv, bolt: Lv, thunder: Lv, aura: Lv, frost: Lv }  // 0=未拥有
}
```

- 移动：输入向量归一化 × speed × speedMult × (冲刺 ? 3.2 : 1)。
- 冲刺：`dashTimer=0.16s` 期间无敌（接触与弹幕伤害均免疫）；`dashCdTimer=2.2s`。
- 受击：`invulnTimer=1.2s` 期间忽略碰撞；闪烁用 `Math.sin` 调制 alpha。

### 3.5 武器系统（weapons.js）

每种武器暴露 `update(game, player, dt)`，内部按自身计时器触发：

| 武器 | 实现要点 |
|---|---|
| 符火 orbit | 火苗角速度 2.4 rad/s；按"玩家→火苗"径向线段扫掠判定（`distToSegment2`），覆盖贴身敌人；对每个敌人维护 `hitCd`（0.4s）防重复判定 |
| 飞星 bolt | 自动锁定最近敌人（距离 < 700），按 `fireRate × cdMult` 发射；`pierce` 穿透计数 |
| 雷印 thunder | 间隔触发，随机选场上有敌人的目标，落雷 Particle + 范围伤害，lv5 连锁 3 目标 |
| 墨潮 aura | 每 0.5s 对半径内敌人 tick 伤害；渲染为呼吸光环 |
| 冰棱 frost | 周期扩散冰环（Particle 环），命中施加 `slowTimer=2.5s`（移速 ×0.55） |

伤害统一入口 `damageEnemy(enemy, amount, game)`：吃 `dmgMult`、触发飘字、死亡结算（掉宝石/击杀数）。

### 3.6 刷怪系统（game.js `Spawner`）

- 计时器按 `interval = max(0.28, 1.45 − t/240)` 触发，每波 `1 + floor(t/110)` 只（v2.0.1 调整，原 t/75，见 §11）。
- 敌人类型按时间解锁（见 config 敌人表），在已解锁池中加权随机（墨点权重最高）。
- 生成位置：屏幕外 60px 的随机边界点（保证从视野外走入）。
- 精英波：`t ≥ 60` 后每 45s 生成 3–5 只精英（基础类型 × 精英系数，`elite=true`）。
- Boss：`t = 150` 生成，之后每 150s…（**实做：每 105s**），出场有横幅提示 + 屏幕震动。
- 强度缩放（按 `t` 秒）：`hp ×(1+t/90×0.5)`、`speed ×(1+t/300×0.25)`、`dmg ×(1+t/120×0.35)`（hp 为 v2.0.1 调整，原 t/60×0.55，见 §11）。

### 3.7 升级系统

- `xp >= xpNext` → 进入 `levelup`，`level++`，`xpNext = 8 + (level-1)×7`，生成候选 3 张卡。
- 候选生成规则：
  1. 每种武器 `Lv<5` 时可作为候选；**未拥有的武器权重 ×3**（保证构筑体验）；
  2. 属性强化按剩余层数过滤（`急救` 不过滤）；
  3. 从池中**不放回抽 3**；不足 3 张时用"急救"填充。
- 应用效果 = 修改 `player.stats` / `player.weapons` / `maxHp`，即时生效。
- UI：DOM 卡片（非 Canvas），点击或按 1/2/3 触发；`levelup` 状态冻结世界。

### 3.8 碰撞与伤害结算（每帧）

```
1. bullets(friendly) × enemies      → 穿透/消亡 + damageEnemy
2. enemies × player                 → 接触伤害（受击无敌判定）
3. bullets(enemy) × player          → 弹幕伤害
4. gems × player(拾取半径)          → 磁吸飞行 → 触碰吸收
5. particles/floaters               → 纯表现，无碰撞
```

### 3.9 渲染管线（每帧绘制顺序）

```
背景(宣纸底色+暗角) → 墨潮光环 → gems → particles(下层)
→ bullets → enemies(墨团) → player(光核+拖尾) → particles(上层)
→ floaters → Boss 血条 → 屏幕震动偏移应用于整层
```

- 敌人墨团：`createRadialGradient` 缓存按半径分档（避免每帧建渐变），外加轻微抖动（`sin(t + seed)`）模拟墨晕。
- 粒子：普通圆点 + 透明度衰减；受击墨溅、击杀消散、冰环、落雷均为粒子组合。
- 屏幕震动：`shake = decay(shake, dt)`，渲染时 `ctx.translate(rand×shake, rand×shake)`。

### 3.10 音频（audio.js）

- 首次用户手势（点击开始）时 `new AudioContext()`（规避自动播放策略）。
- 合成器封装：`beep({freq, type, dur, vol, slide})` + 预设：`hit / shoot / pickup / levelup / dash / boss / death / click`。
- 同类音效限流（如拾取每 60ms 最多一次）防止刷屏爆音。
- `M` 键切换 `muted`（存 localStorage）。

## 6. 性能预算与降级策略

| 项 | 预算 | 超预算降级 |
|---|---|---|
| 同屏敌人 | 260 | 停止刷怪直到回落 |
| 粒子 | 500 | 丢弃新粒子 |
| 宝石 | 400 | 与最近宝石合并经验 |
| 渐变对象 | 按半径分档缓存 | 8px 一档，共约 10 档 |
| 帧时间 | < 16ms | 掉帧时优先削减粒子上限（简单自适应：fps<45 时 particleCap×0.6） |

## 7. 错误与边界处理

- 窗口失焦 → 自动暂停（`blur` 事件），防挂机误判。
- dt 钳制 50ms：切换标签页回来不跳帧、不瞬移。
- Boss 生成时若敌人数已达上限，释放普通敌人名额（杀掉最远的 5 只墨点）。
- 升级候选不足 3 张时以"急救"补位，保证界面始终 3 选 1。

## 10. 第二轮新增系统实现（v2.0）

### 10.1 输入生命周期（P0）
- `clearInput()` 统一清空 `keys` 与 `player.dashTimer`；触发点：`blur`、`visibilitychange(hidden)`、暂停/恢复、开始新局、胜利、结算。
- 持续按键只认"按住"状态，任何焦点/状态切换后旧按键不沿用，杜绝丢失 keyup 后持续移动。
- 冷却计时（`dashCdTimer`）属规则计时而非输入状态，切换不清零（防"切窗刷冲刺无敌"）。

### 10.2 胜利与结算一次性（P0）
- `update()` 帧首判定 `time >= 300` → `showVictory()`：清输入 → `settleRun()`（写存档，`settled` 标志保证**每局只结算一次**）→ `victory` 态展示数据。
- `victory` 态：Enter/「继续无尽」→ `continueEndless()`（`endless=true` 回到 playing，不重播胜利）；E/「结束本局」→ `gameOver(true)`。
- `gameOver(fromEnd)` 带 `state === 'gameover'` 防重入；结算标题区分三种结局：「长夜终结」（未达胜利）/「守夜成功 · 长夜终结」（胜利后主动结束）/「无尽失败 · 已守夜成功」（无尽中死亡）。
- 胜利判定在同帧**优先于**死亡结算（A2-5 回归测试覆盖）。

### 10.3 新敌人 AI（P1，entities.js + game.js updateEnemies）
- **裂锋客 lancer**：有限状态机 `chase → aim → dash → recover`。蓄力开始时锁定方向（`aimX/aimY`），蓄力期画红色预警线；冲刺 620px/s 不可转向，接触伤害 ×1.5；冲刺后硬直 0.9s。
- **墨幕使者 caster**：`chase → cast`。保持 260px 距离，蓄力 1.1s（圆形预警圈）后生成 `Zone`（墨幕）：区域内玩家移速 ×0.75、持续 6s；`killEnemy` 中按 caster 归属驱散其 zones（优先杀施法者反制）。
- 新增 `zones[]`（持续区域）与 `pendings[]`（延迟事件）两个集合，帧内统一更新。

### 10.4 Boss 两阶段（P1，game.js updateEnemies/bossRing/enterBossPhase2/bossFan）
- 生命低于 50% 触发 `enterBossPhase2`（仅一次，`phase2Done` 防重）：移速 ×1.25、屏幕震动、切换攻击组。
- 一阶段：每 4s `bossRing`（12 发环形弹幕）。二阶段：每 2.6s `bossFan`（7 发扇形）+ 每 5.5s `pendings` 落地面墨痕（预警 1s → `Zone` 伤害区：半径 110 / 4.5s / 每跳 12 伤害）。

### 10.5 武器进化（P1，weapons.js + config.js EVOLUTION_POOL）
- 任一武器满 Lv5 后对应进化卡以高权重进入三选一池（`rollCards`），每种限一次（`player.evolved` 标志）。
- 焚墨环：`p.timers.evoRing` 周期 230px 火环 + `burnTimer/burnDps` 灼烧 DOT（updateEnemies 内结算）。
- 贯星阵：bolt 全部 `pierce: Infinity`；每第 5 发（`boltShot % 5`）换 5 发宽扇面大弹。
- 连霆：thunder 命中点推入 `pendings`（`kind:'thunder2'`），1.2s 后二次爆轰（0.85×伤害 / 半径 75）。

### 10.6 水墨可读性（P1，entities.js + game.js drawBackground）
- 背景改浅色宣纸（`#eee2c6` + 纸纹 + 暗角）；敌人按类型绘制不同剪影（圆/梭/刺/方/锐角/环）与色相；弹幕青白、星火金黄、危险区朱红预警。
- `randomEnemyType()` 修复见 §11。

## 11. 兼容处理与规则变更（相对 v1.0）

| 变更 | 原规则（v1.0） | 新规则（v2.0） | 原因与兼容 |
