# 长夜点灯 · The Last Lamplighter

> 太阳沉睡了三年。今夜，四盏古灯熄灭。  
> 提着你唯一的旧灯，穿过暗影，把黎明带回来。

一款完全原创、可离线运行的俯视角灯火动作小游戏。第二轮保留约 45 秒的短夜主线，并加入 3–5 分钟的远征长夜、三张地图、三种长灯取舍与两种新敌人。

**无需安装、无需联网、无需启动服务器。双击 `index.html` 即可游玩。**

`《长夜点灯》标题页`（原测试记录）

## 立即开始

1. 双击根目录的 **[index.html](index.html)**。
2. 选择「开始守夜」（短夜）或「远征模式」。
3. 在出发准备页选择地图与长灯，点击「踏入长夜」。
4. 建议使用桌面 Chrome / Edge，或手机横屏游玩。

> 游戏使用浏览器原生 Canvas 2D 与 WebAudio，所有画面和声音均由代码实时生成，没有外部图片、字体、音频或网络请求。

两种模式都会保存各自的最佳记录。模式、地图、长灯类型会记住上次选择。

## 怎么玩

### 短夜

1. **点亮四角古灯**：靠近古灯，按住交互键直到光环亮起。每次点灯消耗 15 灯油，随后恢复 30 灯油与 1 颗心。
2. **回到中央灯塔**：四灯皆亮后，走到灯塔旁按住交互键，唤醒长灯。
3. **守住最后二十秒**：暗影会疯狂涌来。留在灯光里，用灯火灼退它们，活到天亮。

### 远征

1. **四灯**：与短夜相同。
2. **运油**：靠近长灯油自动背起，送回中央长灯；携带时移动更慢，受伤会掉落。
3. **追灯**：击败 3 名携灯影。它们会引导 1.4 秒窃取古灯；看到连线就转火。
4. **清雾**：击败 3 名缠雾者。落雾前有 1.1 秒预警圈；雾带会减速并耗油，可用灯火烧开。
5. **唤醒**：回到长灯，守住最后三十秒。

失败条件：生命归零，或倒计时结束前没有完成唤醒。

### 灯火就是资源

- 不按键时，身边有一圈微光，能造成少量伤害。
- 按住灯火会射出一道灼热光束，能快速驱散暗影并减速它们，但会持续消耗灯油。
- 暗影有 26% 概率掉落橙色「余烬」，靠近即可拾取，补充 12 灯油。
- 站在已点亮古灯的光环中会缓慢回复灯油。
- 疾步（Shift / 疾步键）带有短暂无敌，是穿过包围的最佳方式。

## 三张地图

| 地图 | 特点 |
|---|---|
| 旧村四角 | 四角旧灯，路线直白，均衡基准 |
| 林间环路 | 四灯围环、路程更短，暗影生成 +20% |
| 冻河折线 | 两座窄桥横跨冻河；涉水减速并流失灯油 |

冻河的水面在 `y = 470–550`，桥在 `x = 300–410` 与 `x = 870–980`。走桥还是涉水，是每趟运油都要做的选择。

## 三种长灯

| 类型 | 收益 | 代价 |
|---|---|---|
| 回油灯 | 古灯光环回油 +2/秒 | 灯火伤害 −15% |
| 守夜灯 | 古灯光环半径 +25、伤害 +2 | 灯火油耗 +15% |
| 引路灯 | 显示目标方向、点灯快 20% | 灯油上限 −12 |

## 五种暗影

| 暗影 | 特点 |
|---|---|
| 游影 | 小而快，成群扑来 |
| 夜行 | 更慢、更耐打，会绕行 |
| 渊影 | 体型大、伤害高，受击退较弱 |
| 携灯影 | 追逐已点亮古灯，引导 1.4 秒后压制 7 秒；击杀归还灯芯并 +10 油 |
| 缠雾者 | 1.1 秒预警后放置雾带；雾中减速 48%、每秒 -1.4 油；灯火可烧开 |

携灯影与任务缠雾者不会被古灯/长灯环境光环自动清除，必须由玩家处理。

## 游戏特色

- **双模式**：短夜快速闭局，远征五段行动推进。
- **光与油的取舍**：照明即战斗，也在烧掉生存资源。
- **地图改变走法**：环路高压、冻河择路，不只是换背景。
- **长灯改变打法**：续航、守护、寻路三套明确取舍。
- **可读的新威胁**：窃灯连线、落雾预警，都有反制窗口。
- **程序化美术**：纸雕剪影、雾、灯火与暗影，全部由 Canvas 实时绘制。
- **程序化音效**：风声、火声、钟声与黎明和弦由 WebAudio 合成。
- **双端完整操作**：键鼠与双摇杆触屏都能完成整局。
- **无依赖**：纯 HTML / CSS / JavaScript，离线可玩。

## 本地测试

游戏本身没有构建步骤。若安装了 Node.js（本项目在 20.11.1 下验证）：

```bash
node --check js/core.js
node --check js/audio.js
node --check js/game.js
node --test tests/core.test.js
```

多种子模拟（开发辅助）：

```bash
node tests/balance-sim.js 36 expedition
node tests/balance-sim.js 30 short
```

浏览器 P0 回归（需要工作区外的 Playwright Core 与本机 Chrome）：

```powershell
npm install playwright-core --prefix "$env:TEMP\night-game-playwright"
$env:NODE_PATH="$env:TEMP\night-game-playwright\node_modules"
$env:CHROME_PATH="C:\Program Files\Google\Chrome\Application\chrome.exe"
node tests/ui-regression.cjs
```

## 兼容性与说明

- 已在 Windows 11 + Chrome 156（headless）下完成桌面、手机竖屏与横屏自动化验收。
- 使用标准 HTML5、CSS、Canvas 2D 与 WebAudio；理论上支持近年的 Chrome / Edge / Firefox / Safari。
- 手机竖屏可玩，但游戏世界是 16:9，横屏视野更完整。
- 进度只保存在浏览器本地 `localStorage`；禁用本地存储时，游戏仍可正常游玩，只是不保存记录。
- 正式入口不暴露 `#debug` 接口；调试入口仅用于开发验收。
- 建议关闭浏览器省电模式，以获得稳定的动画效果。

### 证据边界

本轮真实执行了单元测试、多种子模拟、浏览器自动化流程与响应式检查。浏览器流程由自动化控制器操作，**不是人类手动试玩**；未做实体手机、读屏器、Safari/Firefox 与长时间运行实测。具体证据与未覆盖项见 [TEST_REPORT_ROUND2.md](TEST_REPORT_ROUND2.md)。
