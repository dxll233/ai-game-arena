## 8. 已知限制

1. **Safari / Firefox 未在本轮实机执行**。实现仅使用标准 Canvas 2D / WebAudio / Pointer Events，理论上兼容，但未做浏览器矩阵验证。
2. **手机竖屏视野较小**。完整地图固定为 16:9；未实现竖屏相机缩放，横屏为推荐体验。
3. **没有中途存档**。刷新会结束当前一局；仅保留最高分与最快通关。
4. **屏幕阅读器支持为基础级**。关键按钮有 aria-label 与焦点态，但 Canvas 游戏世界本身不可被读屏逐项朗读。
5. **平衡模拟使用完美瞄准脚本**，其 100% 通关率不代表真人首局体验；真人难度受瞄准、探索与操作习惯影响。
6. **本地记录依赖 `localStorage`**。在禁用本地存储的隐私模式下，游戏可玩但不会保存记录。
