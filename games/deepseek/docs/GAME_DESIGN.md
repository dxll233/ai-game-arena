# 《长夜点灯》游戏设计文档

> English title: **The Last Lamplighter**  
> 类型：单人 · 俯视角 · 灯火动作生存  
> 平台：桌面浏览器 / 手机浏览器  
> 版本：2.0（第二轮，2026-11-02）  
> 基线：1.0 的短夜四灯流程完整保留

---

## 1. 一句话概念

世界尽头的最后一夜，你提着一盏会灼烧暗影的旧灯，在黑暗中点亮四座古灯，再赶回灯塔迎接黎明。

第二轮在同一套“光既是武器，也是代价”的规则上，增加两条明确路线：

- **短夜巡守**：约 45 秒可完成的原版闭局，适合快速重玩。
- **远征长夜**：3–5 分钟的分段行动，四灯之后还要运油、追灯、清雾，最后守住长灯。

玩家始终在「照亮」与「保留灯油」之间做取舍。每一次按住灯火，都会让自己更安全，也让灯油更少。

---

## 2. 设计支柱

1. **光即武器，也是代价。**  
   灯火能灼伤暗影、照亮道路，但持续燃烧会消耗灯油。玩家必须不断在战斗、赶路与补给之间取舍。

2. **短夜有闭环，长夜有段落。**  
   短夜保留“四灯 → 返塔 → 20 秒”的完整起承转合；远征把同一夜拆成五个由行动推进的目标段，不靠等待凑时长。

3. **地图要改变走法，不只改变颜色。**  
   林间环路用更短的路程换更高生成压力；冻河折线用窄桥与涉水成本改变路线选择。

4. **每种威胁都有可读的反制窗口。**  
   携灯影有 1.4 秒窃灯引导，缠雾者有 1.1 秒落雾预警；玩家能看见、能打断、能夺回。

5. **手不忙，心要稳。**  
   操作仍只有移动、瞄准、亮灯、疾步、交互五个动作。难度来自走位、灯油与敌群，而非复杂按键。

## 3. 两种模式

| | 短夜巡守 | 远征长夜 |
|---|---|---|
| 目标 | 四灯 → 返塔 → 守住 20 秒 | 四灯 → 运 5 罐油 → 猎 3 名携灯影 → 清 3 名缠雾者 → 返塔守住 30 秒 |
| 总时限 | 5:00 | 7:00 |
| 最终守夜 | 20 秒 | 30 秒 |
| 目标推进 | 四灯后直接返塔 | 五个连续行动阶段 |
| 记录 | `night_bestScore` / `night_bestElapsed` | `night_bestScore_expedition` / `night_bestElapsed_expedition` |
| 适用 | 快速一局、熟悉规则 | 完整体验第二轮新增内容 |

两种模式都从标题页进入。开始守夜默认短夜；远征模式有独立入口，也可以在出发准备页切换。模式、地图、长灯类型会记忆到本地。

## 4. 世界观与叙事

> 极北之地的太阳已有三年没有升起。  
> 村民靠灯塔「长灯」驱散暗影，直到今夜，长灯熄灭。  
> 你是最后一位守灯人。四座古灯散落在村外，只有重新点燃它们，灯塔才会苏醒。  
> 天亮之前，把灯带回家。

叙事不通过长对话展开，而通过环境与短提示呈现：黑暗中的低语、古灯点燃时的钟声、最终守夜时天空逐渐泛白。开场提供三行字幕，可跳过。

### 情绪曲线

| 阶段 | 玩家目标 | 情绪 |
|---|---|---|
| 0–30 秒 | 熟悉移动与灯火 | 好奇、微紧张 |
| 点亮第 1 盏灯 | 获得第一处安全区 | 成就感、松一口气 |
| 点亮第 2–3 盏 | 敌群变强，灯油吃紧 | 压迫、取舍 |
| 点亮第 4 盏 | 短夜返塔；远征进入运油 | 希望、急迫 |
| 远征第 2–4 段 | 运油、追灯、清雾 | 目标变化、持续行动 |
| 最终守夜 | 在灯下守住黎明 | 高潮、释放 |
| 胜利 | 天亮了 | 温暖、完成感 |

## 5. 核心循环

### 5.1 短夜巡守

```
观察暗影与灯油
    ↓
移动到目标古灯 / 拾取灯油
    ↓
按住灯火，灼退挡路的暗影
    ↓
靠近古灯，按住交互点燃（消耗灯油）
    ↓
古灯提供治疗、灯油与短暂安全区
    ↓
四灯皆亮 → 回到灯塔 → 撑过最后 20 秒 → 黎明
```

### 5.2 远征长夜

```
四灯皆亮
    ↓
第 2 段：寻回 5 罐长灯油，逐罐背回灯塔
    ↓
第 3 段：击败 3 名携灯影，阻止它们熄灭古灯
    ↓
第 4 段：击败 3 名缠雾者，用灯火清掉雾带
    ↓
第 5 段：回到长灯，启动 30 秒最终守夜
    ↓
黎明
```

每个阶段的推进条件都是“完成动作”，不是“活够时间”。阶段切换会回复 1 颗心、+20 灯油、清除普通暗影，并给至少 1.2 秒的换段喘息。

失败条件：

- 生命归零；
- 倒计时结束前未完成当前模式的唤醒条件。

## 6. 操作设计

### 桌面端

| 动作 | 按键 |
|---|---|
| 移动 | `W A S D` / 方向键 |
| 瞄准 | 鼠标 |
| 持续亮灯 | 按住鼠标左键 / `空格` |
| 疾步 | `Shift` |
| 交互（点灯 / 唤醒长灯） | 按住 `E` |
| 暂停 | `Esc` / `P` |
| 静音 | `M` |

### 手机端

- 左侧虚拟摇杆：移动。
- 右侧虚拟摇杆：瞄准；按住即持续亮灯。
- 右下角「疾步」按钮。
- 靠近古灯时出现「点灯」按钮，按住直到完成。

### 操作原则

- 灯火方向与瞄准方向一致。
- 亮灯时移动速度降低 15%，形成“开火承诺”。
- 疾步有无敌帧与冷却，是唯一的紧急避险手段。
- 交互进度在松开按键后缓慢回退，不因受击直接清零，避免过度挫败。
- 携带灯油时移动速度 ×0.88；受击会掉落，0.9 秒后可重新拾取。

## 7. 玩家角色

| 属性 | 数值 |
|---|---|
| 生命 | 4 颗心 |
| 移动速度 | 198 像素/秒 |
| 体积半径 | 15 像素 |
| 灯油上限 | 100（引路灯为 88） |
| 初始灯油 | 72（不超过上限） |
| 基础微光半径 | 92 像素，2 DPS |
| 灯火射程 | 330 像素 |
| 灯火半角 | 21° |
| 灯火伤害 | 21 / 秒（受长灯类型修正） |
| 灯火减速 | 35% |
| 灯火油耗 | 18 / 秒（受长灯类型修正） |
| 受击无敌 | 1.1 秒 |
| 疾步距离 / 冷却 | 约 118 像素 / 2.5 秒 |
| 疾步无敌 | 0.18 秒 |

### 灯油循环

- 暗影死亡有 26% 概率掉落「油火」，拾取 +12 灯油。
- 点亮古灯立即消耗 15 灯油，随后回复 30 灯油与 1 颗心。
- 站在已点亮古灯的光环内，每秒回复 3 灯油；回油灯额外 +2/秒。
- 灯油为 0 时无法亮灯，微光仍然存在。
- 冻河涉水每秒额外流失 1.5 灯油；雾中每秒流失 1.4 灯油。

> 设计意图：灯油不是“弹药”，而是“专注度”。玩家永远有基础自卫能力，但想快速清场就必须烧油。

## 8. 地图与关卡

固定单屏地图，逻辑分辨率 **1280 × 720**。三张地图共用中央长灯与四灯目标，但路径、风险和生成压力不同。

### 8.1 旧村四角（均衡）

```
┌──────────────────────────────────────┐
│   ◆ 北岭灯                东渡灯 ◆   │
│                                      │
│              ▲ 灯塔                  │
│              守灯人                  │
│                                      │
│   ◆ 西林灯                南岸灯 ◆   │
└──────────────────────────────────────┘
```

- 敌人生成倍率 1.0。
- 四角分布，路线直白，是短夜与新手基准图。
- 古灯：北岭灯、东渡灯、西林灯、南岸灯。

### 8.2 林间环路（高压）

```
┌──────────────────────────────────────┐
│                ◆ 北环灯              │
│                                      │
│   ◆ 西环灯       ▲ 灯塔     东环灯 ◆ │
│                                      │
│                ◆ 南环灯              │
└──────────────────────────────────────┘
```

- 敌人生成倍率 1.2，生成间隔更短。
- 四灯围成环路，路程更短，但更容易被追兵夹击。
- 古灯：北环灯、东环灯、西环灯、南环灯。

### 8.3 冻河折线（路线）

```
┌──────────────────────────────────────┐
│   ◆ 北岸灯                东岸灯 ◆   │
│                                      │
│ ~~~~~[桥]~~~~~~~~~~~~~~[桥]~~~~~~    │
│        冻河：涉水减速、流失灯油       │
│   ◆ 西桥灯                南桥灯 ◆   │
└──────────────────────────────────────┘
```

- 敌人生成倍率 0.95，但路线成本最高。
- 冻河横贯地图，水面逻辑区间 `y = 470–550`。
- 两座窄桥：`x = 300–410`、`x = 870–980`。
- 涉水移动速度 ×0.56，每秒流失 1.5 灯油；桥面不受影响。
- 古灯：北岸灯、东岸灯、西桥灯、南桥灯。

### 8.4 共同规则

- 中央：**长灯灯塔**（半径 46 的碰撞体，最终目标）。
- 四角：四座古灯，交互半径 82。
- 玩家出生点由地图定义。
- 暗影从地图四边外的黑暗中生成，向玩家聚拢。
- 边界由松林、雾、冰面与碎石构成；玩家活动范围保留安全边距。
- 地图不滚动、不生成随机障碍，保证每一局的目标位置稳定。

## 9. 长灯类型

出发准备页三选一，各有明确的收益与代价。

| 类型 | 标签 | 收益 | 代价 |
|---|---|---|---|
| 回油灯 | 续航 | 古灯光环回油 +2/秒（3 → 5/秒） | 灯火伤害 −15%（21 → 17.85 DPS） |
| 守夜灯 | 守护 | 古灯光环半径 +25（110 → 135）、光环伤害 +2（5 → 7 DPS） | 灯火油耗 +15%（18 → 20.7/秒） |
| 引路灯 | 寻路 | 显示目标方向；点灯时间 ×0.8（1.8 → 1.44 秒） | 灯油上限 −12（100 → 88） |

`classic`（旧灯）只保留为内部兼容值，不出现在可选卡片中；不传类型时仍按第一轮原样数值运行。

## 10. 敌人设计

所有暗影都被灯火吸引、被光亮灼伤。它们从边缘出现，优先追逐玩家。

| 敌人 | 生命 | 速度 | 接触伤害 | 分数 | 行为 |
|---|---:|---:|---:|---:|---|
| 游影 | 3 | 100 | 1 | 10 | 数量多，直线扑向玩家 |
| 夜行 | 6 | 70 | 1 | 20 | 更慢、更耐打，会轻微绕行 |
| 渊影 | 14 | 42 | 2 | 60 | 大体型，受击退减少，压迫走位 |
| 携灯影 | 12（任务精英 18） | 72 | 1 | 90 | 追逐已点亮古灯，引导 1.4 秒后窃灯 |
| 缠雾者 | 10（任务精英 13.5） | 54 | 1 | 75 | 1.1 秒预警后放置雾带 |

### 10.1 携灯影

- 优先奔向最近一座“已点亮且未被压制”的古灯，距离超过 700 像素时改为追玩家。
- 靠近古灯 42 像素内开始引导；引导 1.4 秒后古灯被压制 7 秒。
- 引导期间有可见连线与进度；离开范围或目标失效会中断。
- 被压制的古灯失去光环、治疗与回油，但不会永久熄灭。
- 击杀携灯影立即恢复对应古灯，玩家 +10 灯油；任务携灯影还会推进第 3 段。
- **反制窗口**：看到连线就转火，1.4 秒内打死或逼退；不要等灯灭了再追。
- 携灯影与任务缠雾者对古灯光环、最终守夜光环免疫，避免挂机自动清任务。

### 10.2 缠雾者

- 在玩家附近进入 1.1 秒落雾预警，地面出现圆形预告。
- 落雾后生成半径 82 的雾带，持续 7 秒，生命 16。
- 玩家在雾中移动速度 ×0.52（减速 48%），每秒流失 1.4 灯油。
- 灯火锥可对雾带造成伤害并清除；缠雾者死亡会清掉场上所有雾带。
- 任务缠雾者第一次落雾冷却仅 0.35 秒，之后按常规冷却。
- **反制窗口**：看到预警圈先横向离开，或提前把灯火对准落点；被罩住后不要硬穿，先烧开雾再走。

### 10.3 通用规则

- 暗影在古灯光环内持续受伤并被减速 30%；长灯守夜光环减速 25%。
- 微光每秒造成 2 点伤害；灯火每秒造成 21 点伤害（可被长灯类型修正）。
- 暗影之间有分离力，避免完全重叠。
- 同时存活上限 46 只；任务敌人可额外突破 4 只上限。
- 生成间隔从 1.9 秒逐渐缩短到 0.9 秒；每点亮一座古灯，生成速度提高 15%，再除以地图生成倍率。
- 最终守夜阶段生成间隔固定为 0.58 秒，并提高夜行、渊影比例；远征守夜额外混入 10% 缠雾者。

### 10.4 受击反馈

- 玩家受击：屏幕震动、红色边缘闪烁、短暂无敌、击退。
- 暗影受击：白色闪白、击退；死亡时化作烟尘与少量余烬。
- 暗影接近玩家时，眼睛微光变亮，提供可读的威胁预警。
- 古灯被窃：灯光转暗、红色脉冲、目标栏提示。
- 雾带：蓝色半透明圆、中心「雾」字与生命条；清除时散开。

## 11. 远征阶段细节

| 段 | 标题 | 完成条件 | 推进方式 | 阶段奖励 |
|---|---|---|---|---|
| 1 | 四灯 | 点亮 4 座古灯 | 逐灯交互 | 每灯 +100 分；第四灯后至少 45 秒 |
| 2 | 灯油 | 送回 5 罐长灯油 | 靠近自动背起，回到长灯 108 像素内自动交付 | 每罐 +120；完成 +150 |
| 3 | 追灯 | 击败 3 名携灯影 | 一次只刷 1 名任务精英，击杀后刷下一名 | 完成 +200；每杀回 1 心 +10 油 |
| 4 | 清雾 | 击败 3 名缠雾者 | 一次只刷 1 名任务精英，击杀后刷下一名 | 完成 +200；每杀回 1 心 +10 油 |
| 5 | 唤醒 | 回到长灯，按住交互 | 30 秒最终守夜 | 完成 +250；时间至少补到 60 秒 |

补充：

- 第 2–5 段开始时：+1 心、+20 灯油、清除普通暗影、生成计时至少 1.2 秒。
- 第 3、4 段每杀一名任务敌人：+1 心、+10 灯油、清除普通暗影、立即刷下一名。
- 第 2 段携带灯油时受伤会掉落；灯油不会消失，可回头再捡。
- 第 5 段开始会清除所有古灯压制与雾带，保证最终守夜有干净起点。
- 最终守夜 30 秒；长灯光环从半径 120 扩张到 210，每秒 6 DPS，并为玩家回 3 油/秒。

## 12. 难度与节奏

### 短夜

| 时间 / 进度 | 生成间隔 | 敌人构成 | 设计目的 |
|---|---:|---|---|
| 0:00–0:30 | 1.9 s | 游影为主 | 教学与热身 |
| 0:30–1:30 | 1.7 s | 游影 + 夜行 | 建立灯火清场节奏 |
| 1:30–3:30 | 1.4 s | 加入渊影 | 迫使玩家使用疾步 |
| 3:30–结束 | 1.0 s | 混合 | 灯油压力 |
| 最终守夜 | 0.58 s | 高压混合 | 20 秒高潮 |

短夜整局倒计时 **5:00**。点亮四灯后，若剩余时间少于 45 秒，则补足至 45 秒。最终守夜一旦开始，倒计时替换为 20 秒黎明进度。

### 远征

- 总时限 **7:00**，正常完成目标会持续推进，不设“原地等倒计时”的空档。
- 四灯后进入运油，路线被拉长；运油减速让玩家必须规划安全路径。
- 追灯段把“守灯”变成“主动出击”，携灯影会逼玩家离开安全区。
- 清雾段用地面封锁改变走位，要求玩家在输出与清路之间分配灯油。
- 最终守夜 30 秒，比短夜多 10 秒，作为整局的高压收束。

设计目标：短夜熟练玩家约 40–60 秒；远征首次完整游玩约 3–5 分钟。实际时长受路线、战斗与是否回头捡油影响。

## 13. 界面与信息层级

### 游戏内 HUD

- 左上：生命（4 颗心）、灯油条。
- 顶部中央：模式名、倒计时 / 黎明进度、四盏灯状态点、远征 5 段进度点。
- 右上：得分、暂停、静音。
- 底部中央：当前目标一句话。
- 靠近古灯：交互提示与环形进度。
- 右下（触屏）：疾步按钮与点灯按钮。

信息优先级：**生命 > 灯油 > 当前目标 > 倒计时 > 得分**。

### 屏幕状态

1. **标题页**：游戏名、副标题、开始守夜、远征模式、如何守夜、记录、音效。
2. **出发准备**：模式、地图、长灯类型、摘要、踏入长夜 / 返回标题。
3. **序章**：三行短句，可跳过。
4. **游戏中**：HUD 与场景。
5. **暂停**：继续、重新开始、玩法、返回标题；显示当前模式 / 地图 / 长灯 / 阶段。
6. **失败**：死因文案、统计、再试一次。
7. **胜利**：黎明动画、统计、再守一夜；显示模式 / 地图 / 长灯 / 阶段。

### 文案基调

克制、略带诗意，不使用网络梗。失败不嘲讽玩家。

示例：

- 失败：「灯灭了。但夜还没有结束。」
- 胜利：「第一缕晨光落在灯罩上。你守住了这一夜。」
- 灯油不足：「灯油不足以点燃古灯。」
- 携灯影：「灯芯被夺走了。追上它。」
- 缠雾者：「雾带封路。用灯火烧开。」

### 可访问性状态

- 当前提示使用 `#toast`，`role="status"`、`aria-live="polite"`、`aria-atomic="true"`。
- 显示时 `aria-hidden="false"`；隐藏、暂停、切换界面、重开时清空文本、类名与定时器，并设 `aria-hidden="true"`。
- 非当前提示不得残留在可访问树中。
- 按钮使用真实 `<button>`，保留键盘焦点态。
- 页面失焦自动暂停并清空持续按键。
- 触屏按钮热区不小于 48×48 CSS 像素。

## 14. 美术与声音

### 美术方向

「纸雕剪影 + 暖色灯火」：

- 主色：墨蓝 `#07101d`、深青 `#0e2630`、雾灰蓝 `#36505a`。
- 强调色：灯火橙 `#ffb15c`、暖白 `#ffe7b0`、暗影紫 `#6b4b8a`。
- 场景为俯视剪影森林，边缘用层叠松树与雾建立深度。
- 所有图形由 Canvas 2D 程序绘制，无外部图片，保证离线可玩。
- 灯火使用叠加混合与径向渐变；暗影用不规则轮廓、拖尾与两点眼光。
- 最终守夜时，天空从墨蓝逐渐过渡到黎明暖色。

第二轮地图层次：

- **旧村四角**：石阶、枯松、旧村屋脊。
- **林间环路**：环形林带、树冠、林间空隙与更密的树影。
- **冻河折线**：冰面反光、两座窄桥、芦苇与冰裂纹。

### 声音方向

- 环境：低频风声、远处钟鸣、极轻的持续低音。
- 灯火：柔和的噪声燃烧声，随亮灯增强。
- 反馈音：拾取清音、点灯钟声、受击闷响、疾步风声、暗影消散的耳语。
- 新机制复用现有音色：携灯影窃灯用低沉受击音与灯芯熄灭提示；灯芯归复用点灯清音；雾带生成用提示音，雾散用拾取清音与散开粒子。
- 胜利：三音上行和弦。
- 全部音效使用 WebAudio 程序合成；默认开启，可一键静音并记忆设置。
- 首次用户交互后才启动音频，遵守浏览器自动播放限制。

## 17. 验收标准

1. 连续完成“开始 → 提示 → 重开 → 结算”，辅助树中不存在上一阶段/上一局 toast 文本；当前提示仍能由 `status` 正确播报。

6. 893×764、1280×720、390×844、844×390 下界面不溢出、不遮挡关键操作；触屏可移动、亮灯、点灯。
7. 正式入口无调试接口，无控制台错误，无外部资源请求。

## 18. 设计自检

- **是否有清晰的目标？** 有：短夜四灯返塔；远征五段目标逐段推进。
- **是否有取舍？** 有：亮灯耗油，移动与输出互相牵制，点灯需要停留；三种长灯各有代价。
- **是否有成长感？** 有：每点亮一灯，地图多一处补给与安全区；远征每段回复并推进。
- **是否有高潮？** 有：最终守夜与天亮；远征第 5 段回到长灯。
- **是否能在 3–5 分钟内讲完？** 远征按完整路线与战斗设计为 3–5 分钟；短夜熟练玩家约 45 秒。
- **是否依赖外部资源？** 否。
- **是否用等待凑时长？** 否；五个阶段都由玩家行动推进。
