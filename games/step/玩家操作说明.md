# 《霓虹防线 NEON DEFENSE》玩家操作说明

> 版本：v3.0（2026-11-05）。适合完全没玩过的新玩家，5 分钟上手。

## 一、如何启动

双击 `index.html`，用 Chrome、Edge 或 Firefox 等现代浏览器打开即可开始。可以单独复制这个文件到其他电脑游玩。

- 支持平台：Windows / macOS / Linux 桌面浏览器（键鼠操作）。未针对手机触控做官方适配，未在真机验证。
- 窗口大小：推荐 1280×800 左右；1024×700、893×764、768×600 及 390×844 等中小窗口下主菜单与各弹窗按钮均会自动适配在首屏内（v3.0.1 已修复小窗口开始按钮不可见问题），窗口过小时布局仍可用但体验以桌面为佳。
- 需要声音：首次点击页面后音效才会启动（浏览器自动播放限制），点一下画面即可。

## 二、游戏目标

蚀码体潮汐正沿着发光数据通道涌向你的**能量核心**。在道路旁的草地上部署防御塔，挡住 **20 波**敌人；核心生命（初始 20 点）归零即失败，清空第 20 波即胜利。

## 三、基本操作

| 操作 | 说明 |
| --- | --- |
| 鼠标左键 | 点击右侧塔卡选中塔类型 → 点击路径旁草地放置；点击已有塔可选中 |
| 数字键 1-4 | 快速选择机枪塔 / 冰霜塔 / 激光塔 / 溅射炮 |
| U / S / O | 升级 / 出售 / 过载 选中的塔 |
| Enter | 提前开始下一波（剩余秒数 × 2 的奖金） |
| 空格 | 暂停 / 继续 |
| F | 1x / 2x 倍速 |
| M | 音效开关 |
| 右键 / Esc | 取消选择 |
| 顶栏滑块 | 调节音量（0-100%，自动保存） |

**四类防御塔**：机枪塔（高射速、可对空）、冰霜塔（减速、仅对地）、激光塔（无视护甲、可对空）、溅射炮（范围爆破、仅对地）。

**两个主动技能**：
- **过载**（选中塔后按 O）：6 秒内该塔射速 ×1.9、伤害 ×1.5，冷却 20 秒。不能解除冲锋体撞击造成的停火。
- **EMP**（侧栏按钮）：冻结全场敌人 2.5 秒，免费，冷却 45 秒。可打断冲锋体冲锋与护盾节点施法。

## 四、核心机制（v3 重点）

### 1. 敌军情报（赢的关键）

右侧**敌军情报面板**实时显示未来 3 波敌人的构成、特性标签与威胁评级：

- 带 `重甲` 标签（如重甲体护甲 4）：普通子弹伤害大减 → 用**穿甲弹**分支或**激光塔**；
- 带 `飞行` 标签（浮空体）：只有**机枪塔与激光塔**能打 → 提前补对空；
- 带 `冲锋` 标签（冲锋体）：会撞停你的塔 → 用冰霜减速或 EMP 打断；
- 带 `护盾` 标签（护盾节点）：给附近敌人套 50% 减伤盾 → 优先集火它；
- 点 **全部 20 波** 看整场波次时间线，点 **敌人图鉴** 随时查每种敌人的属性与反制建议。

**新敌人首次登场时屏幕上方会弹出提示**（第 3 波浮空体、第 5 波 BOSS、第 6 波护盾节点、第 8 波冲锋体），忘了随时去图鉴重看。

### 2. 进阶分支（Lv.2 后二选一，不可更改）

每座塔升到 Lv.2 后面临**互斥分支**，选定后另一支永久不可购，出售返还总投入的 60%：

| 塔 | 分支 A | 分支 B |
| --- | --- | --- |
| 机枪塔 | 穿甲弹：无视 6 护甲，单体重伤 | 散射弹：同时打 3 个目标 |
| 冰霜塔 | 深寒：减速 66% 持续 2.6s | 霜爆：每 3 秒范围霜爆 |
| 激光塔 | 聚焦：射程 180、DPS 翻倍 | 分束：同时照射 3 目标 |
| 溅射炮 | 破片：爆破半径 +55% | 攻城弹：单体重击 ×2.9 |

没有"全能分支"——看下一波是什么，再决定进阶方向。

### 3. 三张地图与解锁

| 地图 | 特点 | 解锁条件 |
| --- | --- | --- |
| Z 字通道 | 经典折返，路径最短 | 默认解锁 |
| 回字双环 | 双环回折，一座塔可覆盖两段路 | 通关 Z 字通道 |
| 长蛇深渊 | 逆向超长直道，敌人生命 +18% | 通关回字双环 |

## 五、存档说明

- **自动保存**：音量/静音、每张地图的最佳波次与得分、是否通关、地图解锁进度，全部存在浏览器本地（localStorage），关掉页面再打开还在。
- **不支持局内存档续玩**：单局约 12-18 分钟，属"一局一把"设计；刷新或返回主菜单即结束本局（避免复杂中局状态损坏存档的风险）。纪录在结算时写入。
- **清档方式**：清除浏览器该页面的站点数据（或 localStorage 中的 `nd_save_v3` 键）即可重置全部进度。
- 存档损坏时游戏自动恢复默认设置并提示，不会卡住不能玩。

## 六、退出与重开

- **退出**：直接关闭浏览器标签页即可（进度已自动保存）。
- **重开**：失败/胜利界面点"再来一局 / 再打一场"；局内按空格暂停后也可"返回主菜单"换地图重开。重开会清空上一局所有塔、敌人与技能冷却，不继承任何残留状态。

## 七、新手建议

1. 第 1 波准备期（15 秒）先建 2-3 座塔再开波，资金优先升级而不是铺量。
2. 每波开打前看一眼情报面板的下一波构成，缺对空补对空、缺破甲进阶穿甲。
3. EMP 留给 BOSS 波或成群重甲/冲锋体，过载给击杀数最高的塔。
4. 打不过就看看敌人图鉴的"反制"一栏，八成是分支选错了方向。
