## 0.5 热修（v3.0.1，2026-11-05）：主菜单"开始游戏"按钮在中小视口被挤出屏幕

**用户反馈**："游戏无法开始"。

**根因**（三重布局问题叠加，仅影响高度 ≤700px 或宽度 ≤900px 的窗口；1280×800 与 893×764 恰好放下故未暴露）：

1. `.ov-card` 是 flex 列布局子项，默认 `flex-shrink:1`——主菜单内容 909px 被父容器高度压缩到 568px，"开始游戏"按钮随卡片内部滚动区藏到首屏之外；
2. 三张地图卡总宽 544px 超过菜单卡内容宽 440px，被迫竖排成 459px 高，将按钮推到距卡片顶 769px 处；
3. 中小屏下弹层 `position:absolute` 受画布区高度限制（1024×700 时弹层仅 460px 高）。

**修复内容**（纯 CSS，未改任何游戏逻辑）：

| 文件 | 改动 |
| --- | --- |
| `index.html` CSS | `.ov-card` 加 `flex-shrink:0`（禁止被压缩）+ `max-height:min(calc(100vh - 40px),100%)`（兜底内部滚动）；菜单卡 `max-width` 520→640px、地图卡宽 180→170px（三卡横排所需） |
| `index.html` CSS | 新增 `@media(max-width:1100px){.overlay{position:fixed;z-index:100}}`（弹层覆盖整个视口）；原 media 查询写在基础规则**之前**导致被层叠覆盖，已移到基础规则之后 |
| `index.html` CSS | `@media(max-width:560px)`：地图卡 2 列网格、隐藏操作速查表与氛围介绍段（保证极窄屏按钮首屏可达）、菜单卡 padding 收紧 |

**验证**：6 视口（1280×800 / 1024×700 / 893×764 / 768×600 / 390×844 / 360×640）按钮全部首屏可见可点、点击进入游戏正常、无横向溢出（截图 40-43）；5 类弹层 3 视口按钮可达；Node 仿真 169 项无回归；浏览器试玩 27 项无回归（含机器人 20 波通关、重开 10 次、失焦恢复）。发布版 `发布版/霓虹防线.html` 已同步。

## 1. v3.0 重大更新：敌军情报系统（A2 核心升级）

**动机**：v2.0 的互斥分支虽有取舍，但玩家看不到 2-3 波后的敌人构成，分支选择缺乏信息支撑；特殊敌人首次出现无任何解释。

**新增**（`index.html`，全部数据驱动，零硬编码 UI）：
- **侧栏"敌军情报"面板**：实时显示当前/接下来 3 波的敌人构成（名称 × 数量 + 特性标签：重甲/飞行/冲锋/护盾/BOSS + 威胁评级 ★）。威胁值按该波敌人总生命（含波次与地图缩放）实算，与波次表严格一致（测试断言递增性与边界）。
- **波次时间线弹窗**（"全部 20 波"按钮）：一屏总览 20 波组成，4 个 BOSS 波高亮。
- **敌人图鉴弹窗**（"敌人图鉴"按钮）：6 种敌人的生命/速度/护甲/赏金/泄漏 + 特性 + **反制建议**，可随时重看。
- **首遇教学 Toast**：每种敌人本局首次登场弹出机制说明；分阶段引导（第 1/3/5/6/8 波）把新知识放在低风险波次。
- 底栏保留"下一波"速览 chips（向后兼容 v2.0 习惯）。

**体验改变（A2 两个具体情境）**：
1. **第 10 波 = BOSS + 浮空体 ×8**：玩家从时间线预知后，可提前把机枪塔进阶为**散射弹**（3 目标对空）而非穿甲弹，并在 BOSS 拐角集中激光——若选穿甲则单发漏飞怪。决策改变结果。
2. **第 12 波 = 浮空体 ×10 + 重甲体 ×3 + 护盾节点**：情报显示重甲+护盾组合，玩家选择**穿甲弹/激光**破甲并留 EMP 打断节点施法；若按 v2.0 习惯均衡发展，则会被 50% 减伤盾拖到漏怪。技能时机与分支选择成为可解释的决策。

## 1. A1：Boss 数量与生命公式统一（P0）

**问题（第一轮基线，复现留证）**：设计文档写"第 20 波 BOSS×2、终局约 3680 生命"，而 `WAVES[19]` 实际生成 1 个 Boss、`spawnEnemy()` 实际产出约 14170.78 生命。文档与实现不一致（以复现时的实测值为证：`spawnEnemy('boss')` 在 w=20、hpMul=1 时 hp=14170.77585）。

**裁定**：遵循实现的单 Boss 基线，删除文档旧值，公式全文唯一：

```
HP(w) = 880 × (1 + 0.15×(w-1)) × 1.35^(⌊w/5⌋-1) × (w≥20 ? 1.7 : 1) × 地图hpMul
```

| 波次 | 代入 | HP（hpMul=1.0） |
| --- | --- | --- |
| 5 | 880 × 1.60 × 1.35⁰ | 1408.00 |
| 10 | 880 × 2.35 × 1.35¹ | 2791.80 |
| 15 | 880 × 3.10 × 1.35² | 4971.78 |
| 20 | 880 × 3.85 × 1.35³ × 1.7 | 14170.77585 |

**改动文件**：
- `index.html`：新增 `bossHpAt(w, mapHpMul)` 唯一公式函数并导出到调试接口（`spawnEnemy` 内 BOSS 分支与公式一致，浮点不取整）。
- `DESIGN.md`：第 7.1 节写入唯一公式与逐项计算表，删除"2 个 Boss / 3680"旧值；波次表第 20 波改为单 Boss 组成。
- `tools/simulate.js`：A1 断言波次表长度、Boss 位于 5/10/15/20、第 20 波单 Boss、w=5/10/15/20 运行时 HP 与公式及文档表逐项相符（0.01 容差）。
