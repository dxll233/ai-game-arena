# 霓虹防线 NEON DEFENSE

一款纯前端、零依赖的 2D 塔防小游戏：在赛博霓虹网格上部署四类防御塔，守护能量核心，抵挡 20 波"蚀码体"潮汐。**3 张地图 · 四塔互斥进阶 · 冲锋体与护盾节点两种特殊敌人 · 敌军情报系统**。

> 当前版本 v3.0.1（2026-11-05，含中小视口布局热修）。玩家向完整说明见《玩家操作说明.md》；开发与验收见 DESIGN.md / DEV.md / TEST_REPORT_ROUND2.md。

## 如何运行

- 双击 `index.html`，用 Chrome / Edge / Firefox / Safari 打开即玩。
- 单文件即完整游戏，无需联网或安装依赖。

## 玩法速览

- **目标**：守住能量核心（20 点生命），清除全部 20 波敌人即获胜；生命归零则失败。
- **地图解锁**：Z 字通道默认解锁；通关后依次解锁回字双环、长蛇深渊；每图分别记录最佳波次/得分/是否通关（localStorage 自动保存，含坏档容错）。
- **建造**：点击右侧塔卡或按 1-4 选择防御塔，再点击战场空地放置。
- **四类防御塔**：机枪塔（$50，高射速、对空）、冰霜塔（$65，减速、对地）、激光塔（$115，无视护甲、对空）、溅射炮（$90，范围爆破、对地）。
- **互斥进阶（Lv.2 后 A/B 二选一，不可更改）**：穿甲弹/散射弹、深寒/霜爆、聚焦/分束、破片/攻城弹——看下一波构成再决定（没有全能分支）。
- **敌军情报（v3 核心升级）**：侧栏面板显示未来 3 波敌人构成 + 特性标签 + 威胁评级；"全部 20 波"看时间线；"敌人图鉴"查属性与反制建议；新敌人首次登场有弹窗教学。
- **主动技能**：过载（单塔 6 秒强化，CD 20s）、EMP（全场冻结 2.5s，CD 45s，可打断冲锋/施法）。
- **经济**：击杀赏金 + 清波奖励（25+6w）+ 提前开波奖金（剩余秒数×2）；出售返还总投入 60%。
- **其他**：空格暂停、F 倍速（音效自动抽稀）、M 静音、顶栏滑块调音量（均持久化）。

## 试玩路线（人工验收用）

1. 主菜单选「Z 字通道」→ 开始；阅读开局引导 Toast，确认 HUD 与情报面板。
2. 第 1-4 波：建 2-3 座机枪塔，熟悉放置/升级/出售；第 3 波前留意浮空体提示。
3. 第 5 波：体验 BOSSⅠ（1408 生命）与死亡分裂。
4. 第 6 波：观察护盾节点施法（青色泡），集火节点验证护盾消退。
5. 第 8 波：观察冲锋体蓄力预警与撞塔停火，用 EMP 打断。
6. 任一波次：把一座塔升到 Lv.2，选择 A/B 分支，验证属性变化与互斥。
7. 打开"全部 20 波"时间线与"敌人图鉴"，核对与底栏下一波预览一致。
8. 暂停/恢复、倍速切换、音量滑块与静音、提前开波奖金各试一次。
9. 故意漏怪至生命归零 → 失败界面（含复盘提示）→ 重开，校验状态清空。
10. 回主菜单换「回字双环」「长蛇深渊」各打数波，确认路径/核心/建造判定随图切换；打通 20 波 → 胜利结算并观察纪录写入与下一图解锁。
