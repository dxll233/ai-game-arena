# 《问道2048·修仙录》玩家操作说明

> 适用版本：v2（第二轮）｜ 更新日期：2026-11-05 ｜ 单文件游戏，零安装、零依赖、离线可玩

## 一、如何启动

任选其一：

1. **双击 `index.html`**，用现代浏览器打开即玩。
2. 或本地服务器方式：在游戏目录运行 `python -m http.server 8321`，浏览器访问 `http://localhost:8321/index.html`。

要求：Chrome / Edge / Firefox / Safari 等现代浏览器（开发验证环境为 Chrome 156，Windows）。
无需联网、无需安装任何依赖。手机端：将 `index.html` 传到手机后用浏览器打开即可，滑动操作。

## 二、游戏目标

修仙主题的 2048：每次合成都是一次"境界突破"。

- **经典修仙模式**：从"练气(2)"一路合成到"金仙(2048)"即**飞升成仙**（胜利结算，可选"继续修行"挑战更高境界"道祖"）；棋盘填满且无合法移动则**道消身陨**（失败）。
- **试炼秘境模式**：6 个固定挑战盘，各有目标境界与步数限制，达成目标即"试炼达成"，限步耗尽为"劫数已尽"。通关徽章与最佳步数逐盘保存。

境界表：2练气 → 4筑基 → 8金丹 → 16元婴 → 32化神 → 64炼虚 → 128合体 → 256大乘 → 512渡劫 → 1024真仙 → 2048金仙 → 更高为道祖。

## 三、操作方式

| 操作 | 桌面 | 手机/触屏 |
| --- | --- | --- |
| 移动所有境界牌 | 方向键 ↑↓←→ 或 W/A/S/D | 在棋盘上向上/下/左/右滑动 |
| 撤销（时光倒流） | 点击"时光倒流"按钮 | 同左 |
| 重开本局（重启轮回） | 点击"重启轮回"按钮 | 同左 |
| 切换模式 | 点击顶部"经典修仙 / 试炼秘境"标签 | 同左 |
| 施展法术 | 点击法术按钮（见下） | 同左 |

规则要点：相同境界的牌相撞合成为高一境界（数值翻倍），每次移动中每张牌最多参与一次合成；
每次有效移动后随机空位落一张新牌（90% 练气 / 10% 筑基）；无效移动不消耗任何资源。
合成得分累加为"修为"，历史最高修为显示为"巅峰"。

## 四、法术与灵气（v2 新机制）

每局开始有 **3 点灵气**（界面左上灵珠 ●●●）。法术是有代价的应急手段，**不可**无限清盘：

| 法术 | 消耗 | 调息（冷却） | 效果 |
| --- | --- | --- | --- |
| 乾坤挪移 | 1 灵气 | 2 步 | 随机重排场上所有牌的位置（牌面数值不变） |
| 焚天化劫 | 2 灵气 | 3 步 | 随机移除场上一张**最小**的牌（至少要有 2 张牌） |

- 调息按"有效移动"计数，调息期间同一法术按钮不可再点。
- 灵气耗尽后本局无法再施法；重开本局恢复 3 点。
- 施法与移动共用同一条撤销历史：点"时光倒流"可完整回滚施法（含灵气、调息、牌位与后续落子）。
- 注意：乾坤挪移重排后若直接形成死局，同样判负——施法前看清盘面。

## 五、试炼秘境（6 个挑战盘）

点击"试炼秘境"标签打开选关面板，每盘可反复重试，通关记录独立保存（不影响经典巅峰）：

| 盘 | 目标 | 限制 | 特点 |
| --- | --- | --- | --- |
| 试炼一·聚气成丹 | 合成 64（炼虚） | 不限步 | 入门热身 |
| 试炼二·金丹速炼 | 合成 256（大乘） | 100 步 | 步数规划 |
| 试炼三·一气化三清 | 合成 256（大乘） | 30 步且**不再落新牌** | 纯残局推演，零浪费合成 |
| 试炼四·十面埋伏 | 合成 512（渡劫） | 90 步 | 散乱初盘整理 |
| 试炼五·渡劫生死局 | 合成 1024（真仙） | 80 步 | 高阶残局 |
| 试炼六·飞升之路 | 合成 2048（金仙） | 160 步 | 终极试炼 |

挑战盘中同样可用法术（灵气同为 3 点）。限步盘每一步都宝贵，法术的调息成本会占用有效移动，请权衡使用。

## 六、存档说明

- **自动保存（跨局记录）**：经典"巅峰"最高分与试炼通关徽章/最佳步数存于浏览器 localStorage
  （键 `wd2048_best`、`wd2048_challenges_v1`），关闭页面后保留；v1 老玩家的巅峰纪录自动沿用。
- **无中途存档**：刷新或关闭页面时，**当前进行中的一局**不保留，重新打开从新局开始（与第一轮一致的设计取舍）。
- **清除记录**：浏览器控制台执行 `localStorage.removeItem("wd2048_best"); localStorage.removeItem("wd2048_challenges_v1")` 后刷新；或在浏览器设置中清除本站数据。
- localStorage 不可用（如隐私模式限制）时游戏自动降级为仅本页面内记录，不影响游玩。

## 七、退出与重开

- 退出：直接关闭浏览器标签页即可，无任何后台进程。
- 重开：游戏内点"重启轮回"（经典）或结算界面"再战此关 / 再入轮回"；刷新页面也等于重开新局。

## 八、常见问题

- **按方向键没反应？** 该方向没有任何牌能移动或合成时属于无效移动，不消耗步数；若页面失焦请先点一下棋盘。
- **没有声音？** 音效为浏览器实时合成，首次交互后才出声；系统静音或浏览器禁止音频时自动无声，不影响游戏。
- **胜利后棋盘满了点不动？** 合成 2048 后若选择"继续修行"且盘面无合法步，会立即进入失败结算，属正常判定（第二轮已修复旧版可能卡死的问题）。
- **撤销按不动？** 撤销上限 20 步；结算动画期间（约 150ms）按钮短暂禁用属正常。
