# 《星港守夜人》第二轮更新记录

## 新增

- **三种主动武器**：保留脉冲枪；新增5弹丸近程霰弹枪，以及0.25秒起射、1.15秒满蓄、高伤害穿透的蓄能枪。桌面用1/2/3、Q或武器卡切换，触屏用独立循环按钮。
- **蓄力取舍**：蓄能期间移速降至72%，桌面松开发射，触屏满蓄自动发射；HUD和玩家环形进度同步显示。
- **可选瞄准辅助**：桌面按H开关，默认关闭；开启后稳定锁定同一目标直至其死亡。触屏继续自动瞄准。
- **棱盾卫**：正面只承受30%弹丸伤害，盾牌限速转向，允许冲刺绕后；第2波加入。
- **布雷者**：保持射程并侧移，部署可预告、可触发也可射击拆除的地雷；第3波加入。
- **Boss两种新攻击**：0.75秒预告的锁定齐射，以及0.9秒预告的熔断区。二阶段分别增至5发和3区，并缩短特殊攻击间隔。
- **熔炉环线**：主界面可选的第二场地，三块实体掩体阻挡单位与弹丸，中央热泄带周期预告、激活并交替方向。
- 新增回血/伤害事件日志、武器与蓄力HUD、危险区和掩体的Canvas绘制。

## 修复与加固

- 统一 `healPlayer()` 的上下限、来源日志及终局后拒止；HUD继续在所有伤害和波间修复之后更新。
- 对第一轮“修复12点但HUD仍52”建立同帧复现：52受伤至40，再修复至52，净变化为0；未发现回血失效，不将其伪报为已修复bug。
- 开始/重开清空按键、摇杆、鼠标射击、蓄力、弹丸、危险区和临时状态。
- 升级链延迟回调绑定 `runId`，避免上一局回调污染新局；重复结算保持幂等。
- **修复 P0「点击 02 / 熔炉环线后画面空白」**：`selectArena()` 在菜单状态就把 `arena` 切为 `foundry`，但 `obstacles` 与 `arenaHazard` 只在 `start()` 中初始化；下一帧 `drawArena()` 遍历 `undefined` 抛出 `TypeError: this.obstacles is not iterable`。由于 `loop()` 把 `requestAnimationFrame` 放在 `render()` 之后，该异常令主循环永久停止，之后即使点击「开始守夜」也只改变状态，不再更新或绘制，表现为没有敌人、看不见角色、没有任何事件。修复：构造期即调用 `setupArena()`、切换场地时同步重建场地数据，`drawArena()` 增加空值防御，`loop()` 用 `try/finally` 保证单帧异常不打断主循环并用 `frameErrors` 记录。
- 菜单新增「点击卡片只选择场地，需再点开始守夜」提示，开始按钮显示当前场地名，避免把场地卡误认为关卡入口。
- 新增 `tests/arena-selection.test.cjs`：用真实浏览器按玩家路径「点场地卡 → 等待真实帧 → 点开始守夜」验证两个场地；`tests/browser-smoke.cjs` 也在两次点击之间加入停顿与主循环存活断言。
- 修正 `browser-smoke.cjs` 的失焦断言：headless Chrome 的 `Target.activateTarget` 不产生真实 `window.blur`，改为派发 `blur` 事件验证自动暂停与输入清理，不降低断言强度。
- **订正上一版结论**：此前「第 2 波 / 第二场地不可见，当前版本玩家与敌人可见」的判断基于连续 CDP 点击（中间没有真实渲染帧）和更早版本生成的截图，未覆盖玩家实际时序，属于误判；本轮已按玩家路径复现、修复并留下回归测试与截图 `screenshots/round2/repro-foundry-before-fix.png`、`11-foundry-after-fix.png`。

## 兼容变化

- 保留 `index.html` 直接启动、六波流程、五波配额、原三种敌人、Boss两阶段、鼠标瞄准、按住射击、冲刺、升级、暂停、胜负和本机最高纪录。
- 原“高能弹头/超频扳机/双联脉冲”扩展到三武器；脉冲多发0.88系数不变。
- 没有局中存档；既有 `localStorage` 最高分键 `neonHarborBest` 保持不变。

## 保留限制

- 触屏验收为Chrome触控模拟，不是实体手机。
- 测试脚本与正式游戏分离；没有发布版作弊、跳关、加血或时间加速按钮。
- 性能仅有报告所列设备与场景的短窗口采样，不宣称所有场景稳定60FPS。
- 人工完整通关及其他浏览器的长期压力测试按 `TEST_REPORT_ROUND2.md` 披露。

## 素材来源与许可

- 所有视觉均为项目内 Canvas 2D 几何图形、CSS 与系统字体；没有外部图片、字体或音频。
- 音效由 Web Audio 振荡器实时合成。
- 新增代码与测试在本项目内完成；未读取或复制其他参赛者源码。
