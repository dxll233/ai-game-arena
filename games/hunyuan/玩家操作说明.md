# 《回响 / ECHO》玩家操作说明

## 一、启动

1. 找到 `index.html`（发布版在 `发布版/echo-chamber-玩家版/` 内）。
2. **双击即可游玩**：支持 Chrome、Edge、Firefox 的最新版本。无需安装、无需联网、无需服务器。
3. 全部进度保存在浏览器本地（`localStorage`），下次打开自动恢复。

## 二、游戏目标

每关从起点 `S` 走到出口 `E`。**时间只在你想动时流动**：你的每一步都被记录，每隔几拍，一个「过去的你」会重走你刚走的路，然后**定格在触发那一刻你所站的位置**——这就是**残像**。用残像替你踩踏板、骗守卫、站到你分身乏术的地方。

三星条件：① 通关 ② 集齐本关全部星尘 ③ 步数 ≤ par。

**重要**：除第 1 关教学外，每关的门都是通往出口的**唯一通路**，绕不过去；门必须由残像压住压力板才会开。玩家自己站上板最多只能撑过一拍，所以**每一关都必须真的用到残像、时间锚或望远镜**，光靠走路是过不去的。

## 三、操作

| 按键 | 作用 |
| --- | --- |
| `↑ ↓ ← →` 或 `W A S D` | 移动一步（时间前进一拍） |
| `空格` | 原地等待一拍 |
| `V` | **时间望远镜**：预演一拍（见下） |
| `Z` | 撤销上一拍（本局内无限次，连死亡都能撤回） |
| `R` | 重来本关 |
| `P` | 暂停 / 继续（窗口失焦会自动暂停） |
| `H` | 观看本关参考解演示（**不会**写入纪录） |
| `Esc` | 关卡列表 |

手机/触屏：底部虚拟方向键 + 等待 / 预演 / 撤销 / 重来按钮。

## 四、机关图鉴

- **压力板 / 门**：板被压住时同色门打开，门在每拍**开始时**求值并冻结整拍。因此残像重演途中「擦过」板的那一拍也能开门——抓住这一瞬冲刺是后期关卡的关键技巧；按 `V` 预演能看到残像每拍的位置。
- **残像**：紫色虚线轮廓是正在重演的残像（会沿你走过的路移动）；静止呼吸光的是已定格残像，会永远站住。
- **守卫（箭头）**：沿路巡逻，碰到玩家即失败；撞上残像会被迷惑停一拍并掉头（残像碎裂）。第 15 关的守卫守在**门后走廊**——门开了不代表能过，必须挑它背向咽喉的那一拍冲过去；按 `V` 预演可以看到「原地不动会在第几拍被抓」。
- **尖刺（红三角）**：玩家踩上即失败，残像可安然通过。
- **尖刺压力板（`!`）**：既是板又是尖刺——你踩上去必死，只有残像能替你压住它。
- **时间水晶（青绿菱形）**：集齐全部水晶出口才开启；**拾取瞬间会净化场上全部残像**。
- **时间锚（青绿菱形 `^`）**：踩上（含等待）即记录「位置 + 拍数」；之后诞生的下一只残像会**从锚点出发**重演你最近的动作——等价于把残像投送到你到不了的地方。再次踩锚会覆盖记录。
- **时间望远镜（`V`）**：花一拍预演未来。青色准星 = 每只残像将定格的位置；红色 ✕ = 它会中途被守卫撞碎；紫色菱形 = 下一只残像的出生点；玩家身上的红色脉冲 = 再不动就要死了。**预演消耗一拍**，会打乱残像节奏——是先看清楚，还是抢时间，由你决定。预测在你走下一步后自动过期。

## 五、存档说明

- 进度（关卡解锁、星级、最佳步数）与静音设置保存在浏览器 `localStorage`，键名 `echo.progress`，带版本号与校验和。
- **坏档保护**：存档损坏时，游戏会先把坏数据备份到 `echo.progress.corrupt`（不清除），再从空白进度开始，并在标题屏提示。
- **手动迁移**：在旧浏览器的控制台执行
  `copy(localStorage.getItem('echo.progress'))` 复制存档字符串，在新浏览器执行
  `localStorage.setItem('echo.progress', '粘贴这里')` 即可搬家。
- **清档**：控制台执行 `localStorage.removeItem('echo.progress')` 后刷新页面。
- 参考解演示（H）与自动测试**不会**写入任何纪录。

## 六、支持平台与退出

- 桌面浏览器（Chrome / Edge / Firefox）；移动端浏览器可用（有虚拟按键），布局已适配竖屏。
- 退出：直接关闭标签页即可，进度已实时保存。重开：游戏中按 `R`。
