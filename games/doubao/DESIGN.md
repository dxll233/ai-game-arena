## 1. 游戏概述

| 项目 | 内容 |
|---|---|
| 游戏名称 | 星尘幸存者（Stardust Survivor） |
| 游戏类型 | 俯视角 / 幸存者-like / 生存动作 |
| 单局时长 | 约 2.5 ~ 3 分钟 |
| 操作方式 | 键盘（WASD / 方向键）移动，武器自动开火，鼠标点选升级 |
| 交付形态 | 单个 `index.html`，双击即玩，无需联网与安装 |
| 目标平台 | 任意现代浏览器（Chrome / Edge / Firefox） |

### 一句话卖点

> 在无尽涌来的异星舰队中活下来——自动开火、自由走位、升级三选一构筑你的战机，在第 2 分钟击败巨型母舰。

### 设计支柱

1. **开箱即玩**：移动是唯一操作，开火全自动，10 秒内理解玩法。
2. **成长快感**：每 20~30 秒一次升级三选一，数值与弹道肉眼可见地变强。
3. **压力曲线**：敌人密度随时间持续攀升，2:00 整 Boss 登场把张力推到顶点。
4. **短局循环**：3 分钟一局，失败 / 胜利后一键重开，"再来一把"成本极低。

---

## 2. 核心玩法循环

```
进入战场 → 走位躲避 + 自动射击 → 击毁敌人 → 拾取星尘（经验）
    ↑                                      ↓
    └── 继续构筑 ← 升级三选一（暂停）← 经验槽满
                         ↓
              02:00 母舰(Boss)登场 → 击杀 = 胜利 / 血量归零 = 失败
```

- **玩家只负责站位与抉择**：武器自动锁定最近敌人，移动是规避伤害的唯一手段。
- **升级时游戏暂停**：弹层中 3 选 1，形成短节奏的"构筑时刻"。
- **明确终局**：不是无限模式，2:00 刷出 Boss，击杀即胜利，单局有始有终。

## 3. 系统设计

### 3.1 玩家战机

| 属性 | 初始值 | 说明 |
|---|---|---|
| 生命值 HP | 100 | 归零失败；受击后 0.8 秒无敌帧并闪烁 |
| 移动速度 | 230 px/s | 八方向移动，对角线做归一化 |
| 拾取半径 | 95 px | 星尘进入半径后被吸附 |
| 武器冷却 | 0.65 s | 每轮冷却结束自动锁定最近敌人齐射 |
| 子弹伤害 | 14 | |
| 子弹速度 | 540 px/s | |
| 弹道数 | 1 | 每轮发射子弹数，散射展开 |
| 穿透 | 0 | 子弹可穿透敌人数，0 = 命中 1 个后消失 |
| 护盾层数 | 0 | 每层抵挡一次任意伤害（含撞击） |

碰撞半径：玩家 14 px。接触结算与生存辅助机制：
- **脱战回复**：连续 2.5 s 未受伤后，每秒回复 4 HP。
- **受击脱身冲刺**：无敌帧内移速 ×1.6，保证能穿出怪群包围。
- **撞击弹开**：玩家与普通敌人接触时将敌人弹开（普通力度 170，玩家无敌帧内 300；Boss 免疫弹开），无敌帧内不重复扣血。

### 3.2 武器规则

1. 冷却结束时，若场上存在敌人：锁定**距离最近**的敌人为目标（带速度前置预判）。
2. 按弹道数 `n` 生成子弹，沿目标方向居中对称散射（基础总展开角 = 14° × (n−1)）。
3. 子弹直线飞行，最长存活 1.6 秒（防脱屏）；穿透次数耗尽或超时销毁。
4. **每颗子弹持有 `hitSet`（已命中敌人的稳定 ID 集合）**：同一敌人只被该弹结算一次、只消耗一次穿透（v2.0 修复，见 §9）。
5. **三路线机制可叠加（v2.0）**：
   - **近距聚束（散射路线）**：目标在 300 px（2 级 380 px）内时，扇面系数收束到 0.35（2 级 0.20），近距离火力显著集中。
   - **过载贯穿（贯穿路线）**：每穿透一个新敌人，该弹后续伤害 +22%（2 级 +30%）、弹速 +18%（2 级 +22%）、弹体半径 +0.4（上限 8）。
   - **相位弹（贯穿路线，1 级限定）**：弹丸无视编织者赋予的护盾，直接结算本体；其他防御/碰撞规则不变。
   - **标记追猎（锁定路线）**：同一敌人被连续命中时叠加追猎标记，5 连命中（2 级 4 连）触发一次额外爆发伤害 +80%（2 级 +120%）；2.5 秒未续上则标记清零。
   - **溢出追踪（锁定路线，1 级限定）**：弹丸击杀目标后若仍有穿透余量，自动转向 460 px 内**次近**且未被本弹命中过的敌人。

### 3.3 敌人设计

| 类型 | 外形/颜色 | HP | 速度 | 接触伤害 | 经验掉落 | 特征 |
|---|---|---|---|---|---|---|
| 追击者 chaser | 红色菱形 | 22 | 90 | 10 | 1 | 基础单位，直线追踪 |
| 疾行者 dasher | 黄色三角 | 12 | 140 | 7 | 1 | 速度快，血量低 |
| 重装 brute | 紫色方块 | 65 | 55 | 18 | 3 | 缓慢但高伤高血 |
| **护盾编织者 weaver**（v2.0） | 蓝紫缓转八边形 + 内菱形 | 46 | 58 | 12 | 3 | 每 6 秒为 215 px 内友军（除 Boss 与自己）附加一次护盾，持续 9 秒；施法时有扩散脉冲 |
| **裂变幼体 larva**（v2.0） | 橙色钝圆体 + 浅色核 | 34 | 72 | 10 | 2 | 死亡时迸裂为 3 只快速分裂体；场上存活敌人 ≥ 95 时不分裂（性能/可读性保护） |
| **分裂体 splinter**（v2.0，幼体衍生物） | 橙色小三角 | 8 | 155 | 5 | 1 | 初生带 190 的迸散初速度，随后直线追击，血薄速快 |
| 精英 elite | 青色大六边形 | 230 | 70 | 25 | 10 | 1:35 后定期出现，体积大 |
| 母舰 warden（Boss） | 巨型青色母舰（阶段二转红） | 2200 | 56 | 22 | — | 2:00 登场；50% 血量转换一次阶段；击杀即胜利 |

**护盾规则（编织者赋予）**：每个非 Boss 敌人最多持有 1 层临时护盾（`eshield`）；非相位弹命中护盾时抵挡全部伤害、护盾消失，并对该敌人**消耗本次穿透**（弹丸穿透耗尽则销毁）——护盾会让一发高穿弹被实打实挡下一次。护盾有淡紫色脉动光环，状态全程可视。

**追猎标记（玩家赋予）**：被标记敌人周围环绕粉色点（最多 5 个），爆发时橙色"追猎 +N"飘字。

**全局血量成长**：普通敌人（含编织者/幼体/分裂体）HP 与伤害随时间缩放 —— `HP倍率 = 1 + 时间(秒)/60 × 0.25`；`接触伤害倍率 = 1 + 时间/60 × 0.08`（精英/Boss 不缩放）。

**Boss 技能（双阶段状态机，v2.0）**：
- **阶段 I（HP > 50%）**：持续追踪玩家；每 3.2 秒发射 14 向旋转环形弹幕（敌弹 8 伤、速 190、存活 6 s）；每 14 秒召唤 2 疾行 + 1 追击。
- **阶段转换（一次性）**：HP 首次降至 50% 时触发"阶段转换"横幅、1.3 秒无敌（防止跨阶段弹幕误杀）、白色/红色爆点与震屏；阶段二停用环形弹幕、召唤间隔缩短为 8 秒，机体与血条转红，HUD 标注"阶段 II"。
- **阶段 II（HP ≤ 50%）**：`扇形齐射 ⇄ 预警冲刺` 循环——
  - 静默 1.0 s → **扇形预警 0.7 s**（朝玩家显示红色半透明扇形锥与边界线）→ 9 发、总张角 34°、速 205、伤 8 的扇形齐射；
  - 静默 0.55 s → **冲刺预警 0.7 s**（流动虚线指示冲锋方向）→ 以 380 px/s 冲刺 0.5 s；之后回到扇形循环。
- 阶段转换只在阶段一分支检测一次；Boss 存在期间普通刷怪 75% 概率跳过，保证镜头焦点。

### 3.4 星尘（经验 / 掉落）

- 敌人死亡在其位置掉落星尘晶体，静置 0.35 秒后可被吸附。
- 进入玩家拾取半径 → 以 1300 px/s² 加速（上限 540 px/s）飞向玩家 → 接触即获得经验值。
- **超时自动回收**：星尘存在超过 8 秒后自动飞向战机，防止走位拉远导致经验永久损失。
- 拾取经验立即判定升级；一次拾取可连升多级（每级弹一次升级面板，依次选择）。
- **升级所需经验**：`4 + (等级−1) × 3`（4, 7, 10, 13, ……）。一局预期 8~10 次升级。

### 3.5 升级强化池（三选一）

每次升级从下表随机抽 **3 项不重复**（有叠层上限的项目到上限后移出奖池；池不足 3 项则按现有数量展示）。

> **新手保护（牌运保底）**：前 3 次升级（等级 ≤ 3 时的发牌）若三选一全为非攻击牌，则强制将其中一张替换为伤害/射速/多重射击之一，压缩前期构筑方差，避免纯运气暴毙。

**基础攻击 / 防御（v1 保留 9 项）**

| 强化 | 标签 | 效果 | 叠层上限 |
|---|---|---|---|
| 能量核心 | 攻击 | 子弹伤害 +25% | 6 |
| 过载电容 | 攻击 | 武器冷却 ×0.83（射速 +20%） | 6 |
| 散射组件 | 攻击 | 弹道数 +1 | 4 |
| 穿透弹头 | 攻击 | 子弹穿透 +1 | 3 |
| 相位护盾 | 防御 | 获得 1 层护盾（抵挡一次伤害） | 3 |
| 磁力线圈 | 辅助 | 拾取半径 +35% | 4 |
| 离子推进器 | 机动 | 移动速度 +12% | 4 |
| 复合装甲 | 防御 | 最大生命 +25，并立即回复 25 | 6 |
| 纳米修复 | 防御 | 立即回复 40% 最大生命 | 无 |

**三流派机制卡（v2.0 新增 6 项）**

| 强化 | 标签 | 效果 | 叠层上限 |
|---|---|---|---|
| 扇面齐射 | 散射 | 弹道数 +2，单发伤害 −15% | 2 |
| 近距聚束 | 散射 | 300 px 内弹道大幅收束（扇面系数 ×0.35）；2 级：380 px、×0.20 | 2 |
| 过载贯穿 | 贯穿 | 每穿透一敌：后续伤害 +22%、弹速 +18%、弹体半径 +0.4（上限 8）；2 级：+30% / +22% | 2 |

> **路线设计取舍**：散射路线牺牲单发质量换覆盖；贯穿路线要求弹丸先穿过炮灰再打高价值目标，配合相位弹克制编织者；锁定路线把火力集中在同一目标，溢出追踪减少过穿浪费。三条路线均可与基础攻击牌混搭，不存在"必须凑齐三件套"的门槛。

### 3.6 刷怪导演（Spawn Director）

| 时间 | 事件（权重以代码为准） |
|---|---|
| 0:00 | 开局缓冲 3 秒不出怪 |
| 0:03 | 追击者开始出现，初始间隔 2 s/只 |
| 0:40 | 疾行者加入（72% 追击 / 28% 疾行）；刷怪间隔线性缩短 |
| 0:50 | 重装与**护盾编织者**加入（60% 追击 / 24% 疾行 / 10% 重装 / 6% 编织者） |
| 1:10 | **裂变幼体**加入（46% 追击 / 22% 疾行 / 16% 重装 / 7% 编织者 / 9% 幼体） |
| 1:15 | 22% 概率一次双刷 |
| 1:35 | 首只精英登场，此后每 25 s 一只（场上无精英时） |
| 1:45 | 屏幕红色预警脉冲 |
| 2:00 | **母舰登场**（停顿 + 横幅提示 + 警报音），普通刷怪 75% 跳过 |
| Boss 死亡 | 胜利结算（v2 实测通关时长见 `TEST_REPORT_ROUND2.md`） |

- 刷怪间隔：`lerp(2.0s → 0.78s, clamp(时间/140))`；1:15 起每次 22% 概率额外 +1 只。
- **动态压力阀**：普通怪同场上限 42 只，超出暂停生成（防止怪潮滚雪球合围）；同屏敌人总数硬上限 130（性能与可读性保护）。
- 生成位置：画布边缘外随机一点（距离画面边缘 30~70 px）。

### 3.7 胜负与结算

- **胜利**：Boss HP 归零 → 大爆炸粒子 → 胜利面板（存活时间、击杀数、等级）。
- **失败**：玩家 HP 归零（护盾耗尽后）→ 残骸爆炸 → 失败面板（同上数据 + 提示"再来一次"）。
- 结算面板提供 **【重新开始】** 按钮与按键 `R`；开始面板提供 **【开始任务】** 按钮与按键 `空格 / 回车`。

## 5. 视听设计

### 5.1 视觉

- **基调**：深空黑蓝底 + 霓虹青/品红/黄配色，全部发光元素使用 `shadowBlur`。
- **背景**：两层视差星场（远星慢、近星快，随玩家移动反向平移），星点白色不同明度。
- **玩家**：青色三角战机，朝移动方向转向；尾焰粒子；受击无敌帧内透明度闪烁。
- **子弹**：青色发光圆 + 拖影。**敌弹**：品红色圆环。
- **敌人**：按类型用几何图形区分（菱/三角/方块/六边/巨型母舰），均带描边辉光。v2.0 新增：编织者=蓝紫缓转八边形+内菱形（施法时向外扩散蓝紫脉冲环）；裂变幼体=橙色钝圆体+浅色核；分裂体=橙色小三角。
- **敌方状态可视化（v2.0）**：编织者护盾=敌人脚下淡紫色脉动光环；追猎标记=敌身周围粉色小点（1~5 个）；护盾被击破有"护盾击破"浅蓝飘字。
- **Boss 二阶段演出（v2.0）**：机体与内核由青转红粉；扇形齐射前显示红色半透明扇形锥（脉动填充+两条边界线，R=330、半角 17°）；冲刺前显示红色流动虚线指向锁定方向；阶段转换时白/红双色爆点 + 强震屏。
- **反馈三件套**：击杀爆炸粒子（8~14 粒）、伤害飘字（白色小字向上淡出；追猎爆发为橙色"追猎 +N"）、玩家受击屏幕震动（6 px, 0.25 s）。
- **星尘**：青色小菱形（v≥2 的大星尘更亮），吸附时拖尾。
- 分辨率：逻辑画布固定 960×600；`devicePixelRatio` 适配高清屏；CSS 等比缩放适配窗口。

### 5.2 音效（WebAudio 纯合成，无外部资源）

首次按键/点击时懒初始化 `AudioContext`（规避浏览器自动播放限制）：

| 事件 | 合成方式 |
|---|---|
| 开火 | 方波 880→320 Hz，0.06 s，低音量（连续音设 60 ms 最小间隔） |
| 子弹命中 | 短促噪声 burst，0.05 s |
| 敌人爆炸 | 噪声 + 正弦下扫 300→80 Hz，0.18 s |
| 受伤 | 锯齿波 160 Hz，0.25 s |

## 6. 技术方案

### 6.1 总原则

- **单文件**：`index.html` 内联全部 CSS / JS，无图片、无音频文件、无第三方库、无网络请求。
- 固定逻辑分辨率 + `requestAnimationFrame` 主循环 + `dt` 时间步长（钳制 ≤ 0.05 s 防切后台跳变）。
- 面向对象风格的普通函数 + 实体数组（不引入类继承层级，控制规模）。

### 6.2 代码结构（单文件内分区）

```
<script>
 0. 工具：clamp / lerp / rand / dist / angleLerp
 1. AudioFX：WebAudio 合成器
 2. Input：键盘状态表 + 鼠标点击坐标转换
 3. 全局状态：Game（state, time, kills, 屏幕震动…）
 4. 玩家对象 player（含升级后重算属性）
 5. 实体集合：bullets / enemyBullets / enemies / gems / particles / floaters
 6. 工厂：spawnEnemy(type) / fireWeapon() / dropGems()
 7. 刷怪导演：updateDirector(dt)
 8. 升级：UPGRADES 表 + rollChoices() / applyUpgrade(id)
 9. 更新逻辑：updatePlayer / updateBullets / updateEnemies /
    updateGems / updateParticles / collisions / checkLevelUp
10. 渲染：背景星场 → 实体（按 y 简单排序可选）→ 粒子 → 飘字 → HUD → 弹层
11. 状态界面：drawMenu / drawLevelUp / drawPause / drawEnd
12. 主循环 loop(t) 与初始化 newGame()
</script>
```

### 6.3 关键实现要点

- **碰撞**：圆形距离判定；子弹 × 敌人用每弹独立的 `hitSet`（稳定敌人 ID 集合）去重：一颗子弹对同一敌人最多结算一次、只消耗一次穿透（v2.0 修复，见 §9）；敌人死亡有 `dead` 幂等保护，同帧多弹只结算一次击杀（防 Boss 重复触发胜利结算）。
- **敌人推进**：每帧朝玩家方向归一化移动；多怪重叠允许（不做群体分离，降低算力与卡顿），靠 Brute/Boss 的大体型自然形成压迫。
- **对象回收**：实体采用 `dead` 标记 + 每帧 `filter`（规模 < 300，无需对象池）；粒子上限 340、同屏敌人上限 130。
- **暂停语义**：`levelup` / `pause` 状态下不跑 update，只渲染画面 + 弹层；升级面板打开时玩家免疫（本来就冻结）；失焦 / 标签页隐藏时自动暂停（v2.0）。
- **重开**：`startGame() → resetGame()` 重置全部集合、`nextEid` 与玩家属性，确保无残留监听（监听器只在初始化时注册一次）。
- **稳定性**：所有数值用 `Math.hypot` 防除零（零向量时归一化返回 (0,0)）；WebAudio 用 `try/catch` 包裹，音频失败不影响游戏；主循环 dt 钳制 ≤ 0.05 s；正式页面不暴露任何调试钩子（`window.G/UPGRADES/ETYPES` 均不挂载）。

### 6.4 性能预算

- 同屏对象总数目标 < 400（敌人 130 + 弹幕 120 + 粒子 150）。
- 粒子/飘字设生命上限自动消亡；shadowBlur 仅用于子弹、玩家、星尘、精英/Boss，普通怪用纯色+描边控制填充率。
- 60 FPS @ 960×600（中端笔记本集显为基准）。

## 9. v2.0 缺陷修复记录（P0）

| 编号 | 缺陷 | 根因 | 修复 | 代码位置 |
|---|---|---|---|---|
| A1 | 升级卡"复合装甲 +25"等英文/数字被逐字符折断换行 | 卡牌描述按字符 `fillText` 断行，ASCII 数字串也被拆开 | 新增 `wrapLines` 词元折行：连续 ASCII（字母/数字/`. + % = -`）作为不可拆整体，仅在 CJK 字间与空格处换行 | `wrapLines` / `wrapText` / `drawLevelUp`（`index.html` L1142-1218） |
| A2 | 理论上同一颗子弹可在一帧内对同一敌人重复结算 | 子弹命中后仅依赖穿透计数，重叠帧/多判定路径下缺少"已命中集合" | 每弹 `hitSet:Set` 存稳定 `eid`，命中前查重；敌人 `dead` 幂等保护 | `fireWeapon` / 子弹碰撞循环 / `killEnemy` |
| A3 | 窗口失焦或切后台后按键状态残留导致"鬼移"，且游戏不暂停 | keyup 在窗口外丢失；无 blur/visibility 处理 | `blur` 与 `visibilitychange(hidden)` 统一调 `releaseAllKeys()`：清空按键 + PLAYING 中自动暂停，恢复需手动继续 | 输入区 `releaseAllKeys` |

> 说明：A2 为源码级风险（高穿透弹道 + 同帧重叠时可能触发），通过定点回归测试复现断言并修复；未在真人局中观测到显性故障，不夸大为既有玩家事故。
