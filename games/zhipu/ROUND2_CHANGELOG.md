# 《御剑·破晓》第二轮更新日志（ROUND2_CHANGELOG）

> 版本 v2.0 ｜ 2026-11-02 ｜ 独立开发
> 本轮在第一轮作品上完成可试玩、可验收的实质升级，全部改动只涉及本项目目录。

## 一、新增

### 1. 双模式（P1）
- **破晓 · 十分钟**（原版规则完整保留）：撑满 600 秒天明渡劫，480 秒妖王现世，妖王 1500 血。
- **标准 · 五分钟**（新增）：300 秒结算，235 秒妖王现世，妖王 1000 血；事件调度独立设计（5 项），不是十分钟局的截断。
- 开始界面显示两种模式各自的说明与最佳战绩；战绩按模式分档存储（`yjpx_records` 的 `dawn` / `standard` 两档互不串档，`tests` T12 验证）。

### 2. 三种剑道构筑（P1，机制差异而非数值换皮）
| 构筑 | 核心机制 | 专属升级（各 2 项） |
|---|---|---|
| 剑卫 · 环剑式 | 4 柄环剑近身反击（环剑伤害 19），以贴近妖群换取"剑气回涌"爆发 | 剑气回涌（击杀 30% 概率迸发范围 180 冲击波，1.5× 规模/伤害）、剑盾护体（轨道半径 +40%、接触减伤 25%） |
| 剑仙 · 御气式 | 穿透剑气远程控线（间隔 1.0s、伤害 30） | 寒霜剑意（剑气命中减速 35%）、剑气分光（一次迸发两道剑气） |
| 剑魔 · 遁影式 | 资源型位移：初始 1 层剑意，每 6 次击杀 +1（上限 3），空格影遁消耗 1 层（175px 位移 + 2 秒强化 + 无敌帧） | 遁术精进（冷却 -40%、剑意所需击杀 6→4）、剑随影动（影遁后伤害 +40%，2 秒） |

- 通用升级池共享，构筑专属升级只出现在对应构筑的候选池中（T5b 验证生效参数）。
- 三构筑均可完整打通标准局（T13–T15：每构筑 2 种子 300 秒仿真全胜）。

### 3. 双阶段妖王（P1）
- **一阶段**：每 5 秒"妖嚎"召 3 只小妖。
- **二阶段**（血量 ≤50%，**只切换一次**，`bossPhase2Count` 计数防重）：每 4 秒 8 向环形弹幕、每 7 秒蓄力 0.6 秒后冲刺（横幅"妖王狂怒"）。
- 阶段行为、单次切换、弹幕数、蓄力→冲刺均有测试（T7）；浏览器实测截图确认渲染表现（`screenshots/round2/shot-boss-phase2.png`，t=259.5、bossHp 455/1000）。

### 4. 三类事件（P1，影响路线与资源，非纯横幅）
- **伏击**：同方向并入 8 妖狼 + 1 妖将（标准局），考验走位。
- **灵泉**：泉眼区域 20 秒内持续回血（4/秒）并小幅加快刷怪，引导玩家绕路取舍。
- **天雷**：预警圈 1.2 秒后落雷，圈内玩家 -20 气血、妖物即死（`struck` 标记保证单次结算，T8a）。
- 调度：标准局 5 项（45 伏击 / 90 灵泉 / 140 天雷 / 200 伏击 / 250 灵泉），破晓局 8 项（90/150/210/280/360/430/500/560），两时长各自设计（T8d、T13–T16 计数验证 2/2/1 与 3/2/3）。

### 5. 测试与自动化基础设施
- `tests/run-tests.js`：26 项 headless 自动化测试（node vm + DOM 桩 + 受控接口 `__RG`），覆盖发布隔离、模式边界、暂停、回血四状态、构筑机制、Boss 双阶段、三类事件、重复结算、重开清空、失焦清键、记录隔离，及 7 条完整局仿真（3 构筑 ×2 种子 300 秒 + 1 条 600 秒破晓局，全部胜利）。
- `tests/shot.html` + `tests/capture.js`：真实浏览器（Edge headless + DevTools 协议）截图与性能采样工具，走位 AI 与 `run-tests.js` 同源。
- `tests/interact-test.js`：真实输入链路验证（CDP `Input` 域分发与真实键鼠同一事件路径的可信事件）：入阵/卡片/按钮真实点击、按键按住/释放/连按、暂停恢复、失焦清键、失败结算、连续重开 10 次、回首页与战绩，17 项全部通过。
- `window.__RG` 受控测试接口（正式版内置、文末有边界说明）：仅提供与键鼠等价的程序化驱动（配置/步进/选卡/方向键），**不含时间跳跃与经验直给**；`snap()` 返回只读状态与遥测。

## 二、修复（确认缺陷，先复现后修复）

1. **P0 发布隔离（第一轮评审确认项）**：第一轮 `index.html` 全局键盘监听含 T（快进 60 秒）/ G（直给升级经验）调试键。
   - 修复：正式入口 `index.html` 移除全部调试路径，无 URL 参数开关（源码无 `location.search` / `URLSearchParams`）；调试键移入独立生成的 `dev.html`（`tests/make-dev.js` 注入，含"开 发 版"水印与 DEV 标题）。T2/T2b 校验两份文件的隔离性。
2. **剑卫"剑气回涌"机制缺失（本轮代码审查发现的真实缺陷）**：升级文案承诺击杀触发冲击波，但 `shocks` 数组只被消费、无处生成——升级后无任何实际效果。旧代码下 T6a 恒为 0 冲击波（复现失败条件）；修复为在 `killEnemy` 中按 `player.surge` 概率迸发冲击波。
3. **玄罡护体文案含糊（第一轮评审确认项）**：原"补足气血"无法说明恢复量。文案改为"气血上限加二十五，并立即恢复二十五点气血（不超过新上限）"，与实现一致；T4 验证四状态：100→125/125、99→124/125、75→100/125、50→75/125。
4. **升级选卡越界**：`__RG.choose(9)` 在弹窗开启时错误返回 true（仅 `chooseCard` 内有守卫）。接口层补 `cardOptions[i]` 检查（T9 断言）。
5. **远程击杀经验断档（平衡性缺陷，仿真轨迹诊断确认）**：剑仙等远程构筑击杀远处妖物后，灵气落在拾取半径外，导致等级停滞（仿真中观察到 171 杀仅 6 级）。游戏侧修复（面向真实玩家的 QoL，非测试特判）：拾取半径 60→90；宝石在 2.6 倍拾取半径内以 140px/s 来投；丹药 150px 内 200px/s 来投；灵气掉落随妖物血量同比例成长。
6. **无手势环境控制台刷警告**：`beep` 在 AudioContext suspended 时仍尝试发声，headless/自动播放拦截下每条音效产生一条控制台警告。补 `AC.state === 'running'` 检查（正常游玩首次点击后即 running，无行为变化）。
7. **测试工具缺陷（非游戏代码）**：`tests/shot.html` 性能模式先有"60 秒自冻结"缺陷，修复时引入 `perf` 变量先使用后声明的 TDZ 错误，导致 wrapper 整页加载失败（控制台 `ReferenceError` 复现）。重排声明后以 30 秒短跑验证、再完成 300 秒全程采样。游戏本体不受影响（此前全部截图早于该缺陷引入时完成）。

## 三、平衡与体验调整

| 调整 | 旧 → 新 | 原因 |
|---|---|---|
| 妖物血量/灵气成长 | `(1+t/300)` → `(1+t/360)`（灵气同步） | 300 秒局后期血量过厚导致击杀/经验停滞 |
| 刷怪每波数量 | `1+min(4, t/150)` → `1+min(3, t/150)`；间隔下限 0.35→0.42 | 峰值压力过大（实测峰值仍可达 109 敌） |
| 妖魂（wraith）速度 | 135 → 128 | 与三构筑移速（210/240/225）拉开可走位差距 |
| 剑卫环剑伤害 | 16 → 19 | 剑卫近身定位的风险回报补偿 |
| 剑仙剑气伤害/间隔 | 26/1.1s → 30/1.0s | 早期（1–90 秒）压制力不足，易掉血 |
| 丹药掉率 | 0.10 → 0.12 | 配合事件节奏的资源补给 |
| 灵泉持续 | 25s → 20s（横幅同步"二十息"） | 标准局 250 秒最后一次灵泉不与终局重叠 |

## 四、兼容与保留

- **600 秒破晓模式规则不变**：第一轮"撑满十分钟即胜利"的原规则原样保留，本轮所有加法对旧模式透明（仅新增 Boss 阶段与事件内容）。
- **入口不变**：正式入口仍是 `御剑破晓/index.html`，双击即玩，零依赖、零素材、可离线。
- **存档**：`localStorage` 使用两个键——`yjpx_pref`（模式/构筑偏好）与 `yjpx_records`（分模式战绩）。缺失或损坏时自动初始化空档，不影响游玩；两种模式战绩互不串档（T12）。
- **调试捷径隔离**：`dev.html` 为生成文件（不手工编辑），与正式版同逻辑仅注入 T/G 与水印；正式版无任何调试路径（T2）。

## 五、保留限制（已知未做）

- 触屏/移动端布局未承诺、未实现（仅支持键盘）；本轮按指导仅验证 893×764 与 1280×720 桌面布局。
- 音频为 WebAudio 合成音效，无背景音乐。
- `__RG` 接口在正式版内保留（用于自动化验收），但全部为与键鼠等价的只读/驱动能力，无法通过它获得时间或经验捷径。
- 性能采样基于 headless Edge 单机环境（详见 TEST_REPORT_ROUND2.md），未在多台真机上测试。

## 六、素材来源

- **零外部素材**。全部视觉由 Canvas 矢量绘制 + 离屏预渲染精灵生成；全部音效由 WebAudio 振荡器实时合成；字体使用系统楷体（KaiTi/STKai 系）栈，无网络请求、无第三方资源、无外部许可依赖。测试工具（tests/ 下）为项目自制，零 npm 依赖。
